Довідник: зразки й generic-параметри

Усі види зразків (patterns), що використовуються в switch, if case, for case, catch і оголошеннях, а також формальний опис generic-параметрів: цілочисельні параметри, where-умови і generic-аргументи.

У книзі: patterns · genericparametersandarguments

Зразки

Зразок описує форму значення, з якою значення порівнюють і з якої витягують частини. Зразки бувають двох груп:

  • деструктуруючі — розбирають значення, що завжди має цю форму: заповнювач, ідентифікатор, прив'язування значення, кортеж. Їх можна використовувати в let, var, for-in. У for-in і оголошеннях кортеж-зразок може містити лише заповнювачі, ідентифікатори, опціональні й вкладені кортежні зразки — наприклад, let (status, true) = reply не скомпілюється, бо true — зразок-вираз. Параметр-кортеж замикання в заголовку розбирається лише як особливий випадок: pairs.forEach { (n, s) in … } працює, а замикання з явним типом ((Int, Int)) -> Int і заголовком { (a, b) in … } не скомпілюється. Надійний спосіб — { pair in let (a, b) = pair … };
  • умовні — можуть не збігтися: варіант enum, опціонал, приведення типу, вираз. Використовуються лише в switch, if case, guard case, while case, for case, catch.

Заповнювач

_ збігається з будь-яким значенням і відкидає його:

Swift
let (_, status) = response          // відкидаємо перший елемент
items.forEach { _ in counter += 1 }  // параметр замикання не потрібен

Ідентифікатор

Ім'я, з яким значення зв'язується: let total = 42 — total тут зразок-ідентифікатор. Якщо ліворуч від = у let/var стоїть ідентифікатор, він збігається з будь-яким значенням.

Прив'язування значення

let або var перед зразком прив'язує всі вкладені ідентифікатори до відповідних частин значення:

Swift
let session = (user: "ann", ttl: 3600)
switch session {
case let (name, ttl) where ttl > 0:     // let поширюється на обидва
    print(name, ttl)
case (let name, var ttl):               // або для кожного окремо
    ttl += 60
    print(name, ttl)
}

Кортеж

Список зразків у дужках: (x, 0), (_, let y), (1..<10, "ok"). Кортеж з одного елемента — це просто зразок у дужках. Якщо кортеж-зразок має анотацію типу, кожен елемент має відповідати типу.

Варіант перелічення

.варіант або Тип.варіант, за бажанням з кортежем-зразком для асоційованих значень:

Swift
enum Push {
    case promo(campaign: String, discount: Int)
    case reminder(daysLeft: Int)
    case silent
}

switch push {
case .promo(_, let d) where d >= 50:
    showBanner(d)
case .promo(let campaign, _):
    track(campaign)
case .reminder(daysLeft: 0...1):
    showUrgent()
case .reminder, .silent:
    break
}

Цей зразок збігається й з опціональним значенням, якщо варіант не має конфлікту з Optional.none/.some. Тобто для let push: Push? можна писати case .promo: без ? — Swift автоматично розгорне опціонал.

Опціонал

зразок? — збігається з .some(значення), де значення відповідає внутрішньому зразку:

Swift
let tokens: [String?] = ["a1", nil, "b2"]
for case let token? in tokens {
    print(token)                // лише не-nil
}

switch Int("42") {
case let n? where n > 0: print("додатне \(n)")
case _?: print("не додатне")
case nil: print("не число")
}

Приведення типу

  • is Тип — збігається, якщо значення в рантаймі має цей тип (або підтип); нічого не прив'язує;
  • зразок as Тип — приводить і порівнює з внутрішнім зразком:
Swift
switch payload {
case is NSNull: print("null")
case let n as Int: print("ціле \(n)")
case let (code, message) as (Int, String): print(code, message)
default: break
}

Вираз

Будь-який вираз як зразок. Порівняння відбувається через оператор ~=. Стандартна реалізація для Equatable — це ==, а для діапазонів — contains:

Swift
switch httpStatus {
case 200: print("OK")
case 300..<400: print("Перенаправлення")
case 400...: print("Помилка")
default: break
}

Перевантаживши ~=, можна навчити switch нових видів порівнянь:

Swift
struct Prefix { let value: String }

func ~= (pattern: Prefix, value: String) -> Bool {
    value.hasPrefix(pattern.value)
}

switch "pro_monthly" {
case Prefix(value: "pro_"): print("Преміум-план")
case Prefix(value: "lite_"): print("Базовий план")
default: print("Невідомий план")
}

Generic-параметри

Список параметрів

<параметри> після імені функції, типу, ініціалізатора чи сабскрипта. Кожен параметр — ім'я, за бажанням з обмеженням:

Swift
func merge<Key: Hashable, Value>(_ a: [Key: Value], _ b: [Key: Value]) -> [Key: Value]
struct Pair<First, Second> { }

Обмеження: протокол, композиція протоколів, клас (тип має бути його підкласом) або придушене обмеження ~Copyable/~Escapable.

Існують також пакети параметрів (each T) для функцій і типів з довільною кількістю generic-параметрів. На них, наприклад, побудовано ViewBuilder у SwiftUI, що приймає будь-яку кількість дочірніх view:

Swift
func describeAll<each T>(_ value: repeat each T) -> [String] {
    var parts: [String] = []
    repeat parts.append(String(describing: each value))
    return parts
}
describeAll(1, "two", 3.0)   // ["1", "two", "3.0"]

Цілочисельні generic-параметри

Параметр може бути значенням типу Int, а не типом. Оголошується через let:

Swift
struct FixedBuffer<let Capacity: Int, Element> {
    var storage: InlineArray<Capacity, Element>
}

let frames = FixedBuffer<60, Double>(storage: InlineArray(repeating: 0))

func zeros<let N: Int>() -> InlineArray<N, Int> {
    InlineArray(repeating: 0)
}
let z: InlineArray<4, Int> = zeros()     // N виведено як 4
print(FixedBuffer<8, Int>.Capacity)      // 8 — доступ як до статичної константи

Правила:

  • тип параметра — Int (або псевдонім, що зводиться до Int);
  • аргументом може бути цілочисельний літерал або інший цілочисельний generic-параметр з оточення; звичайні константи, generic-типи і пакети — ні;
  • значення доступне як статична константа типу (для параметрів типу) чи як константа в тілі функції;
  • значення може виводитися з типів аргументів;
  • на цілочисельний параметр не можна накласти протокольне чи класове обмеження, а рівність значень можна вимагати в розширенні: extension FixedBuffer where Capacity == 4 { }.

Головний споживач цієї можливості в стандартній бібліотеці — InlineArray<count, Element>: масив фіксованого розміру, що зберігається без виділення пам'яті в купі.

where-умови

where перед тілом оголошення задає додаткові вимоги:

Swift
func syncAll<S: Sequence>(_ items: S) where S.Element: Codable & Sendable { }

extension Dictionary where Value: Numeric {
    func total() -> Value { values.reduce(0, +) }
}

Види вимог:

  • T: Протокол або T: Клас — відповідність чи успадкування;
  • T == U, T.Element == String — рівність типів;
  • T: ~Copyable — придушення неявного обмеження.

Generic-оголошення можна перевантажувати за where-умовами: компілятор обирає найспецифічніше. Умови вкладеного оголошення (методу в generic-типі) додаються до умов охопного типу.

Generic-аргументи

Конкретні типи (або цілочисельні значення) в кутових дужках при використанні generic-типу: Array<Int>, Dictionary<String, [Date]>, FixedBuffer<16, UInt8>. Аргументи мусять задовольняти обмеження параметрів. Явно вказувати аргументи для generic-функцій не можна — вони виводяться з контексту виклику; для ініціалізаторів generic-типів можна: Set<Int>().

Перевір себе

Обери відповідь — одразу побачиш, чи правильно, і пояснення.

1. Які зразки можна використовувати в let, var і for-in?

Умовні зразки (варіант enum, опціонал, приведення типу, вираз) можуть не збігтися, тому вони працюють лише в switch, if case, for case, catch тощо.

2. Чому тут помилка компіляції?

Swift
let reply = (200, true)
let (status, true) = reply
print(status)

В оголошеннях кортеж-зразок може містити лише заповнювачі, ідентифікатори, опціональні й вкладені кортежні зразки.

3. Що надрукує цей код?

Swift
let response = (404, "Not Found")
let (_, text) = response
print(text)

Заповнювач _ збігається з першим елементом і відкидає його.

4. Що надрукує цей код?

Swift
let session = (user: "ann", ttl: 0)
switch session {
case let (name, ttl) where ttl > 0:
    print("active", name)
case (let name, var ttl):
    ttl += 60
    print(name, ttl)
}

Перша гілка не проходить через where ttl > 0; у другій var ttl прив'язує змінну копію, яку можна змінити.

5. Чим є кортеж-зразок з одного елемента, наприклад (x)?

Одноелементних кортежів у Swift немає: дужки лише групують зразок.

6. Що надрукує цей код?

Swift
enum Push {
    case promo(discount: Int)
    case silent
}
func handle(_ push: Push?) {
    switch push {
    case .promo(let d) where d >= 50: print("big \(d)")
    case .promo: print("small")
    case .silent: print("silent")
    case nil: print("none")
    }
}
handle(.promo(discount: 30))
handle(nil)

Зразок варіанта збігається й з опціональним значенням — Swift автоматично розгортає Push?. 30 не проходить умову >= 50.

7. Що надрукує цей код?

Swift
let tokens: [String?] = ["a1", nil, "b2"]
for case let token? in tokens {
    print(token)
}

Зразок token? збігається лише з .some(...), тож nil пропускається, а значення вже розгорнуте.

8. Що надрукує цей код?

Swift
func run() {
    let items: [Any] = [1, "two", 3.0]
    for item in items {
        switch item {
        case let n as Int: print("int \(n)")
        case is String: print("string")
        default: print("other")
        }
    }
}
run()

let n as Int приводить і прив'язує, is String лише перевіряє тип; 3.0 — Double, тож іде в default.

9. Що надрукує цей код?

Swift
struct Prefix { let value: String }

func ~= (pattern: Prefix, value: String) -> Bool {
    value.hasPrefix(pattern.value)
}

func plan(_ id: String) -> String {
    switch id {
    case Prefix(value: "pro_"): return "premium"
    case Prefix(value: "lite_"): return "basic"
    default: return "unknown"
    }
}
print(plan("lite_year"), plan("trial"))

Зразок-вираз порівнюється через оператор ~=, і його перевантаження вчить switch нового виду порівняння.

10. Що надрукує цей код?

Swift
func describeAll<each T>(_ value: repeat each T) -> [String] {
    var parts: [String] = []
    repeat parts.append(String(describing: each value))
    return parts
}
print(describeAll(1, "two", 3.0))

Пакет параметрів each T приймає будь-яку кількість аргументів різних типів, а repeat повторює вираз для кожного.

11. Що не може бути обмеженням generic-параметра, наприклад у <T: ...>?

Обмеженням може бути протокол, композиція протоколів, клас або придушене обмеження на кшталт ~Copyable.

12. Що надрукує цей код?

Swift
struct Ring<let N: Int> {
    func capacity() -> Int { N }
}
print(Ring<8>().capacity())

Параметр let N: Int — це значення, доступне в тілі типу як константа.

13. Що можна передати як аргумент цілочисельного generic-параметра?

Звичайні константи, generic-типи і пакети як аргументи не підходять.

14. Що надрукує цей код?

Swift
func kind<T>(_ x: T) -> String { "any" }
func kind<T>(_ x: T) -> String where T: Numeric { "number" }
print(kind(5), kind("a"))

Generic-оголошення можна перевантажувати за where-умовами — компілятор обирає найспецифічніше, що підходить.

15. Яке твердження неправильне?

Явно вказувати аргументи для generic-функцій не можна — вони виводяться з контексту виклику.

Практика
  1. Напиши switch над (Int?, String?), що окремо обробляє всі чотири комбінації nil/не-nil.
  2. Перевантаж ~= для ClosedRange<Date> і Date, щоб у switch по даті працювали діапазони сезонних акцій.
  3. Зроби структуру Ring<let N: Int> на основі InlineArray для збереження останніх N значень FPS.
  4. Напиши функцію з пакетом параметрів, що приймає будь-яку кількість Equatable-пар і перевіряє, чи всі пари рівні.
