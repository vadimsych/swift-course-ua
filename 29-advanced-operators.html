Розширені оператори

Бітові операції й зсуви, оператори з переповненням, пріоритет і асоціативність, перевантаження операторів для власних типів, власні оператори й result builders.

У книзі: advancedoperators

Бітові оператори

Працюють з окремими бітами цілих чисел — для прапорців, масок, кольорів, бінарних протоколів.

Swift
let a: UInt8 = 0b1100_1010
let b: UInt8 = 0b1010_0110

~a          // NOT: 0b0011_0101 — інвертує кожен біт
a & b       // AND: 0b1000_0010 — 1 там, де обидва 1
a | b       // OR:  0b1110_1110 — 1 там, де хоча б один 1
a ^ b       // XOR: 0b0110_1100 — 1 там, де біти різні

Практичний приклад — набір прапорців дозволів:

Swift
let canRead:  UInt8 = 1 << 0     // 0b001
let canWrite: UInt8 = 1 << 1     // 0b010
let canShare: UInt8 = 1 << 2     // 0b100

var permissions = canRead | canShare       // 0b101
permissions & canWrite != 0                // false
permissions |= canWrite                    // увімкнути
permissions &= ~canShare                   // вимкнути
permissions ^= canRead                     // перемкнути
Порада

Для наборів прапорців у Swift є протокол OptionSet, що дає типобезпечний синтаксис множин: let p: Permissions = [.read, .write], p.contains(.share). Під капотом — ті самі бітові операції.

Зсуви

<< і >> зсувають біти вліво й вправо.

Беззнакові числа — логічний зсув: біти, що виходять за межі, відкидаються, а звільнені позиції заповнюються нулями. Зсув на n ліворуч — множення на 2ⁿ, праворуч — ділення.

Swift
let argb: UInt32 = 0xFF_3A_7B_C4
let alpha = (argb >> 24) & 0xFF     // 255
let red   = (argb >> 16) & 0xFF     // 0x3A = 58
let green = (argb >> 8)  & 0xFF     // 0x7B = 123
let blue  =  argb        & 0xFF     // 0xC4 = 196

Знакові числа зберігаються в доповняльному коді: найстарший біт — знаковий. При зсуві праворуч звільнені позиції заповнюються знаковим бітом (арифметичний зсув), тому від'ємні числа лишаються від'ємними: -16 >> 2 == -4.

C#

Зсуви працюють так само, як у C#.

Оператори з переповненням

Звичайна арифметика при переповненні — крах (урок про оператори). Якщо загортання потрібне свідомо, використовують оператори з &:

Swift
var hash: UInt32 = 2_166_136_261
for byte in "swift".utf8 {
    hash = (hash ^ UInt32(byte)) &* 16_777_619     // FNV-1a: множення із загортанням
}

let max = Int8.max
max &+ 1      // -128: переповнення вгору загортається до мінімуму
Int8.min &- 1 // 127: переповнення вниз — до максимуму
  • &+, &-, &* — додавання, віднімання, множення із загортанням;
  • &<<, &>> — зсуви, де величина зсуву береться за модулем ширини типу (як у C#).

Для перевірки переповнення без краху є методи addingReportingOverflow(_:) тощо, що повертають (partialValue, overflow: Bool).

Пріоритет і асоціативність

Пріоритет визначає, яка операція виконується першою; асоціативність — як групуються оператори однакового пріоритету (зліва направо чи справа наліво).

Swift
10 - 4 * 2 << 1   // 10 - (4 * (2 << 1)) = -6 — зсув сильніший за множення

Swift об'єднує оператори в групи пріоритетів. Основні, від найвищого:

  1. BitwiseShiftPrecedence — <<, >>
  2. MultiplicationPrecedence — *, /, %, &, &*
  3. AdditionPrecedence — +, -, |, ^, &+
  4. RangeFormationPrecedence — ..., ..<
  5. CastingPrecedence — is, as
  6. NilCoalescingPrecedence — ??
  7. ComparisonPrecedence — ==, <, …
  8. LogicalConjunctionPrecedence — &&
  9. LogicalDisjunctionPrecedence — ||
  10. TernaryPrecedence — ?:
  11. AssignmentPrecedence — =, +=, …
Пастка

Правила відрізняються від C. Зокрема, & має пріоритет множення, а | і ^ — додавання. Тому flags & mask == 0 у Swift читається як (flags & mask) == 0, на відміну від C, де == сильніший. Але в складних виразах краще ставити дужки.

Операторні методи

Класи й структури можуть реалізувати існуючі оператори для своїх типів. Оператор оголошується як статичний метод:

Swift
struct Money {
    var cents: Int
    var currency: String

    static func + (lhs: Money, rhs: Money) -> Money {
        precondition(lhs.currency == rhs.currency, "Різні валюти")
        return Money(cents: lhs.cents + rhs.cents, currency: lhs.currency)
    }

    static func * (lhs: Money, rhs: Int) -> Money {
        Money(cents: lhs.cents * rhs, currency: lhs.currency)
    }
}

let price = Money(cents: 4_99, currency: "USD")
let total = price * 3 + Money(cents: 1_00, currency: "USD")   // 15.97

Префіксні й постфіксні оператори

Унарні оператори позначаються prefix або postfix:

Swift
extension Money {
    static prefix func - (m: Money) -> Money {
        Money(cents: -m.cents, currency: m.currency)
    }
}

let refund = -price

Складене присвоєння

Лівий операнд — inout:

Swift
extension Money {
    static func += (lhs: inout Money, rhs: Money) {
        lhs = lhs + rhs
    }
}

var wallet = Money(cents: 0, currency: "USD")
wallet += price

Оператор присвоєння = і тернарний ?: перевантажити не можна.

Оператори еквівалентності

Для == достатньо оголосити відповідність Equatable: якщо всі властивості Equatable, компілятор синтезує реалізацію сам (урок про протоколи). != з'являється автоматично. Вручну пишуть лише тоді, коли рівність має особливий зміст — наприклад, валюту порівнюємо без урахування регістру:

Swift
extension Money: Equatable {
    static func == (lhs: Money, rhs: Money) -> Bool {
        lhs.cents == rhs.cents
            && lhs.currency.uppercased() == rhs.currency.uppercased()   // "usd" == "USD"
    }
}
C#

Як operator + у C# — теж статичний метод. Зручніше лише те, що оператор можна дописати в розширенні до будь-якого типу, а != з'являється сам.

Власні оператори

Новий оператор спочатку оголошують глобально з ключовим словом prefix, infix або postfix, а потім реалізують:

Swift
infix operator |> : ForwardPipePrecedence

precedencegroup ForwardPipePrecedence {
    associativity: left
    higherThan: AssignmentPrecedence
}

func |> <T, U>(value: T, transform: (T) -> U) -> U {
    transform(value)
}

let slug = "  Hello World  "
    |> { $0.trimmingCharacters(in: .whitespaces) }
    |> { $0.lowercased() }
    |> { $0.replacingOccurrences(of: " ", with: "-") }
// "hello-world"

Оператор може складатися з символів / = - + ! * % < > & | ^ ? ~ і деяких Unicode-символів.

Пріоритет власних infix-операторів

Кожен infix-оператор належить групі пріоритету. Без явного вказання він потрапляє в DefaultPrecedence — вище тернарного, без асоціативності. Власну групу оголошують через precedencegroup з полями associativity, higherThan, lowerThan, assignment.

Префіксні й постфіксні оператори пріоритету не мають. Якщо до операнда застосовано обидва, спочатку виконується постфіксний.

Порада

Власні оператори — сильний, але ризикований інструмент: новий символ незрозумілий новачкам у кодовій базі. Використовуй їх для DSL і математичних типів, а не для звичайної бізнес-логіки.

Result builders

Result builder — тип, що дозволяє будувати складні значення декларативно: як список виразів з if, for і switch, а компілятор сам склеює їх у результат. Саме на цьому побудовано SwiftUI (@ViewBuilder).

Swift
@resultBuilder
enum QueryBuilder {
    static func buildBlock(_ parts: String...) -> [String] {
        parts
    }
    static func buildOptional(_ part: [String]?) -> String {
        part?.joined(separator: " AND ") ?? ""
    }
    static func buildEither(first part: [String]) -> String {
        part.joined(separator: " AND ")
    }
    static func buildEither(second part: [String]) -> String {
        part.joined(separator: " AND ")
    }
    static func buildArray(_ parts: [[String]]) -> String {
        parts.flatMap { $0 }.joined(separator: " AND ")
    }
    static func buildFinalResult(_ parts: [String]) -> String {
        parts.filter { !$0.isEmpty }.joined(separator: " AND ")
    }
}

func whereClause(@QueryBuilder _ build: () -> String) -> String {
    "WHERE " + build()
}

let onlyPaid = true
let countries = ["UA", "PL"]

let sql = whereClause {
    "deleted = 0"
    if onlyPaid {
        "plan != 'free'"
    }
    for code in countries {
        "country <> '\(code)'"
    }
}
// WHERE deleted = 0 AND plan != 'free' AND country <> 'UA' AND country <> 'PL'

Компілятор перетворює тіло замикання на виклики статичних методів builder-а:

  • buildBlock — склеює послідовність виразів;
  • buildOptional — для if без else;
  • buildEither(first:) / buildEither(second:) — для if-else і switch;
  • buildArray — для циклів for;
  • buildExpression — перетворює кожен окремий вираз (необов'язковий);
  • buildFinalResult — фінальне перетворення результату (необов'язковий);
  • buildLimitedAvailability — для if #available;
  • buildPartialBlock(first:) і buildPartialBlock(accumulated:next:) — альтернатива buildBlock, що склеює вирази попарно й дозволяє будь-яку їх кількість.

Builder можна застосувати як атрибут до параметра-замикання, до функції, методу чи обчислюваної властивості (як var body у SwiftUI неявно позначено @ViewBuilder).

Практика
  1. Зроби struct Permissions: OptionSet з read, write, share, admin і перевір операції над множинами.
  2. Розбери 16-бітне значення RGB565 на три компоненти через зсуви й маски.
  3. Реалізуй для struct Vector3 оператори +, -, унарний -, * на скаляр і +=.
  4. Оголоси оператор ??=, що присвоює значення, лише якщо змінна дорівнює nil.
  5. Напиши result builder @MenuBuilder, що будує масив пунктів меню з підтримкою if і for.
