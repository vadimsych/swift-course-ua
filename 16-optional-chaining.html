Опціональні ланцюжки

Як безпечно звертатися до властивостей, методів і сабскриптів через кілька рівнів опціоналів за допомогою ?., і що відбувається з типом результату.

У книзі: optionalchaining

Ідея

Опціональний ланцюжок — це ? після опціонального значення перед зверненням до його члена. Якщо значення nil, решта ланцюжка пропускається, і весь вираз дає nil. Альтернатива — !, але вона на nil падає.

C#

Це той самий null-conditional ?., що й у C#, включно з тим, що a?.Count дає nullable-результат. Різниця в тому, що опціонали Swift однаково працюють для value і reference types, а компілятор не дасть використати результат без розгортання.

Для прикладів візьмемо конфіг віддаленої конфігурації (Remote Config), де майже все може бути відсутнім. Зверни увагу: це структури — опціональні ланцюжки однаково працюють і зі структурами, і з класами.

Swift
struct RemoteConfig {
    var paywall: PaywallConfig?
    var flags: [String: [String]] = [:]
}

struct PaywallConfig {
    var title: String
    var products: [ProductConfig]
    var trial: TrialConfig?

    subscript(slot i: Int) -> ProductConfig? {
        products.indices.contains(i) ? products[i] : nil
    }

    func highlighted() -> ProductConfig? {
        products.first { $0.isHighlighted }
    }
}

struct ProductConfig {
    var id: String
    var isHighlighted = false
}

struct TrialConfig {
    var days: Int
}

var config = RemoteConfig()

Читання й запис властивостей

Swift
let title = config.paywall?.title          // String? — хоча title не опціональний
let days = config.paywall?.trial?.days     // Int?, а не Int??

if let days = config.paywall?.trial?.days {
    print("Пробний період: \(days) днів")
}

Результат ланцюжка завжди опціональний, але лише на один рівень:

  • якщо член не опціональний, він стає опціональним (String → String?);
  • якщо вже опціональний, таким і лишається (Int? → Int?), скільки б ? не було в ланцюжку.

Присвоєння через ланцюжок спрацює лише тоді, коли всі ланки не nil. Інакше нічого не відбудеться — і права частина присвоєння навіть не обчислюється. Тобто якщо праворуч стоїть виклик дорогої функції, вона не виконається:

Swift
config.paywall?.title = makeLocalizedTitle()   // paywall == nil → makeLocalizedTitle() не викликається

Виклик методів

Метод викликається через ланцюжок так само. Результат стає опціональним, навіть для методів без результату: Void перетворюється на Void?. Завдяки цьому можна перевірити, чи виклик узагалі відбувся:

Swift
let didReset: Void? = config.paywall?.products.removeAll()
if didReset == nil {
    print("Пейвола в конфігу немає — нічого скидати")
}

Те саме з присвоєнням: вираз config.paywall?.title = "Pro" має тип Void?, і його можна порівняти з nil.

Сабскрипти

Для сабскрипта ? ставиться перед квадратними дужками — одразу після значення, яке може бути nil:

Swift
let second = config.paywall?[slot: 1]?.id   // String?

Тут два ?: перший — бо paywall опціональний, другий — бо сам сабскрипт повертає опціонал.

Якщо сабскрипт повертає опціонал (як у словника), знак ставиться після закривальної дужки, і так можна змінювати значення всередині:

Swift
config.flags["onboarding"]?.append("skip_intro")   // ключа немає — нічого не відбудеться
config.flags["onboarding"] = ["v2"]
config.flags["onboarding"]?.append("skip_intro")   // ["v2", "skip_intro"]

Методи з опціональним результатом

Якщо метод сам повертає опціонал і ланцюжок треба продовжити від його результату, ? ставиться після дужок виклику:

Swift
let highlightedID = config.paywall?.highlighted()?.id.uppercased()   // String?

? після highlighted() стосується результату методу, а не самого методу.

Порада

Довгі ланцюжки на кшталт a?.b?.c?.d?.e — ознака, що модель даних варто переглянути. Часто зручніше один раз розгорнути проміжне значення через guard let paywall = config.paywall else { return } і далі працювати з не-опціональним.

Перевір себе

Обери відповідь — одразу побачиш, чи правильно, і пояснення.

1. Що надрукує цей код?

Swift
struct Profile { var nickname: String }
struct User { var profile: Profile? }
let user = User(profile: nil)
print(user.profile?.nickname ?? "гість")

profile дорівнює nil, тож ланцюжок дає nil, і спрацьовує ??.

2. Що станеться при виконанні цього коду?

Swift
struct Profile { var nickname: String }
struct User { var profile: Profile? }
let user = User(profile: nil)
print(user.profile!.nickname)

! примусово розгортає опціонал і на nil падає. ?. у такому разі просто дав би nil.

3. Який тип має config.paywall?.trial?.days, якщо paywall і trial опціональні, а days: Int?

Результат ланцюжка опціональний лише на один рівень, скільки б ? не було.

4. Що надрукує цей код?

Swift
struct Paywall { var title = "" }
struct Config { var paywall: Paywall? }
func makeTitle() -> String {
    print("рахуємо")
    return "Pro"
}
var config = Config()
config.paywall?.title = makeTitle()
print(config.paywall?.title ?? "немає")

Якщо ланка ланцюжка nil, присвоєння не відбувається, і права частина навіть не обчислюється.

5. Що надрукує цей код?

Swift
struct Cart {
    var items = ["a"]
    mutating func clear() { items.removeAll() }
}
struct Shop { var cart: Cart? }
var shop = Shop(cart: nil)
let r1: Void? = shop.cart?.clear()
shop.cart = Cart()
let r2: Void? = shop.cart?.clear()
print(r1 == nil, r2 == nil)

Метод без результату через ланцюжок дає Void?: nil, якщо виклику не було.

6. Як правильно взяти перший елемент з names: [String]??

? ставлять одразу після значення, яке може бути nil, перед квадратними дужками.

7. Що надрукує цей код?

Swift
var flags: [String: [String]] = [:]
flags["intro"]?.append("skip")
print(flags.count)
flags["intro"] = ["v2"]
flags["intro"]?.append("skip")
print(flags["intro"] ?? [])

Перший append нічого не робить, бо ключа немає. Коли ключ з'явився, ланцюжок змінює масив у словнику.

8. Що надрукує цей код?

Swift
struct Item {
    var id: String
    var hot = false
}
struct List {
    var items: [Item]
    func highlighted() -> Item? { items.first { $0.hot } }
}
let list: List? = List(items: [Item(id: "a"), Item(id: "b", hot: true)])
print(list?.highlighted()?.id.uppercased() ?? "-")

? після highlighted() продовжує ланцюжок від опціонального результату методу.

9. До чого стосується другий ? у виразі shop?.find()?.name?

? після дужок виклику означає: продовжити, лише якщо метод повернув не nil.

Практика
  1. Для моделі User → Subscription? → Plan? → price: Decimal напиши обчислювану властивість, що повертає ціну як рядок або «Безкоштовно».
  2. Через ланцюжок додай елемент у масив у словнику [String: [String]], якщо ключ існує, і переконайся, що для неіснуючого ключа нічого не станеться.
  3. Перевір через порівняння з nil, чи вдалося присвоєння через ланцюжок.
  4. Порівняй типи виразів a?.b для випадків, коли b — Int, Int? і метод, що повертає Int?.
