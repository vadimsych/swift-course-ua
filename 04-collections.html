Колекції

Array, Set і Dictionary: створення, зміна, ітерація, операції над множинами. Усі три — value types з copy-on-write, і це головна відмінність від List<T> та Dictionary<K,V> у C#.

У книзі: collectiontypes

Змінність колекцій

Колекція в var змінна, у let — повністю незмінна: не можна ні додати елемент, ні змінити існуючий.

Swift
let weekdays = ["Пн", "Вт", "Ср"]
// weekdays.append("Чт")     // помилка компіляції

var queue: [String] = []
queue.append("player1")
C#

Колекції Swift — структури. var b = a для масиву створює логічну копію, а не друге посилання на той самий список. Фізично дані копіюються лише при першій зміні однієї з копій (copy-on-write), тому присвоєння дешеве.

Swift
var original = [1, 2, 3]
var copy = original
copy.append(4)
print(original)   // [1, 2, 3] — у C# з List<int> тут було б [1, 2, 3, 4]

Як читати Array<Int> і Set<String>

Кутові дужки після назви типу вказують, що лежить усередині колекції. Це generic-параметр, як у C#:

Swift C# Читається як
Array<Int>, коротко [Int] List<int> масив чисел
Set<String> HashSet<string> множина рядків
Dictionary<String, Int>, коротко [String: Int] Dictionary<string, int> словник: ключ — рядок, значення — число

Для масиву й словника є короткий запис у квадратних дужках, і саме його пишуть на практиці. Для множини короткого запису немає, тому завжди Set<...>.

Масиви

[Int] — впорядкована колекція: елементи йдуть у тому порядку, в якому їх додали, і до кожного можна звернутися за номером.

Створення

Порожні літерали [] і [:] не несуть інформації про тип, тому потрібна анотація — або змінна, тип якої вже відомий. Тоді присвоєння [] просто очищає колекцію:

Swift
var empty: [Int] = []
var empty2 = [Int]()
var zeros = Array(repeating: 0, count: 5)        // [0, 0, 0, 0, 0]
var level = [3, 1, 4] + [1, 5]                   // конкатенація
let names = ["Ada", "Linus", "Grace"]            // літерал, тип [String]

Доступ і зміна

Більшість операцій має прямий аналог у List<T>:

Що треба C# List<T> Swift Array
кількість, порожній? Count, Count == 0 count, isEmpty
додати в кінець Add(x), AddRange(xs) append(x), append(contentsOf:) або +=
вставити Insert(i, x) insert(x, at: i)
видалити RemoveAt(i) remove(at: i) — повертає видалений елемент
видалити останній RemoveAt(Count - 1) removeLast(), popLast() (опціонал)
видалити за умовою RemoveAll(pred) removeAll(where:)
перший / останній First(), Last() first, last — опціонали, не кидають
замінити діапазон RemoveRange + InsertRange items[a...b] = [...] — будь-якої довжини
Swift
var queue = ["intro", "level1", "level2", "boss"]
queue[1...2] = ["tutorial"]          // два елементи замінено одним
let next = queue.popLast()           // Optional("boss")
queue.removeAll { $0.hasPrefix("tut") }
Пастка

Індекс поза межами — крах, а не виняток, який можна перехопити. deck[10] на масиві з трьох елементів зупинить застосунок. Тому використовуй first, last, indices.contains(i) або власне розширення з безпечним сабскриптом.

Ітерація

Swift
for card in deck {
    print(card)
}

for (index, card) in deck.enumerated() {
    print(index, card)
}

enumerated() повертає пари (позиція, елемент). Позиція — порядковий номер з нуля, і для звичайних масивів збігається з індексом.

C#

Замість LINQ — методи прямо на колекціях: map (Select), filter (Where), reduce (Aggregate), compactMap (Select + відкинути null), flatMap (SelectMany), sorted(by:) (OrderBy), contains(where:) (Any), allSatisfy (All), first(where:) (FirstOrDefault). Вони не ліниві: повертають новий масив одразу. Ліниве обчислення вмикається через .lazy.

Swift
let scores = [120, 45, 300, 80]
let top = scores.filter { $0 > 100 }.sorted(by: >)   // [300, 120]
// $0 — «поточний елемент», автоматичне ім'я параметра замикання (урок 7)
// sorted(by: >) — сортувати за спаданням, передавши оператор > як функцію порівняння
let total = scores.reduce(0, +)                       // 545

Множини

Set<String> — множина рядків: кожне значення в ній може бути лише один раз, а порядку немає. Аналог HashSet<string> у C#. Множина потрібна, коли важливо лише «є елемент чи немає»: які рівні пройдено, які теги вже показано, які продукти куплено.

Масив [String] Множина Set<String>
Дублікати можуть бути лише унікальні
Порядок зберігається немає
contains перебирає всі елементи миттєво
Доступ за номером [0] є немає

Хешування

Елементи множини (і ключі словника) мають бути Hashable. Усі базові типи — String, Int, Double, Bool — уже хешовані, так само як варіанти enum без асоційованих значень. Власні типи стають Hashable, якщо оголосити відповідність, а компілятор згенерує реалізацію (урок про протоколи).

C#

Те саме, що GetHashCode + Equals, але генерується автоматично для структур, у яких усі поля хешовані.

Тип і створення

Swift
var tags = Set<String>()                  // порожня множина рядків
var unlocked: Set = ["forest", "cave"]    // Set<String> — тип елементів виведено
var notASet = ["forest", "cave"]          // без слова Set це масив [String]

Слово Set у другому рядку обов'язкове: квадратні дужки без нього Swift вважає масивом.

Доступ і зміна

Swift
unlocked.insert("castle")
unlocked.count
unlocked.contains("cave")              // true
if let removed = unlocked.remove("forest") {
    print("Прибрано \(removed)")
}
unlocked.removeAll()

Ітерація

Порядок не визначений. Якщо потрібен стабільний — sorted():

Swift
for zone in unlocked.sorted() {
    print(zone)
}

Операції над множинами

Основні

Swift
let owned: Set = ["sword", "shield", "potion"]
let shop: Set = ["potion", "bow", "map"]

owned.union(shop)                 // усе разом
owned.intersection(shop)          // ["potion"]
owned.subtracting(shop)           // ["sword", "shield"]
owned.symmetricDifference(shop)   // усе, крім спільного

Кожна має мутуючу пару: formUnion, formIntersection, subtract, formSymmetricDifference.

Належність і рівність

Swift
let starter: Set = ["sword"]
starter.isSubset(of: owned)          // true
owned.isSuperset(of: starter)        // true
starter.isStrictSubset(of: owned)    // true — підмножина, але не рівна
owned.isStrictSuperset(of: starter)  // true
owned.isDisjoint(with: ["bow"])      // true — спільних немає
owned == ["potion", "shield", "sword"]  // true — порядок не важливий

Словники

Dictionary<Key, Value> — пари ключ-значення без порядку. Ключ має бути Hashable.

Тип і створення

Swift
var prices: [String: Int] = [:]
var stock = [String: Int]()
var levels = [
    "forest": 1,
    "cave": 3,
    "castle": 7,      // кінцева кома дозволена в літералах масивів і словників
]

Доступ і зміна

Сабскрипт повертає опціонал, бо ключа може не бути:

Swift
if let lvl = levels["cave"] {
    print("Печера — рівень \(lvl)")
}

levels["swamp"] = 4          // додати
levels["cave"] = 5           // замінити
levels["forest"] = nil       // видалити ключ повністю
print(levels.count)          // ключа "forest" більше немає

let old = levels.updateValue(9, forKey: "castle")  // повертає старе значення або nil
levels.removeValue(forKey: "swamp")

levels["dungeon", default: 0] += 1   // значення за замовчуванням для відсутнього ключа

Присвоєння nil видаляє ключ, а не зберігає порожнє значення. Значення в цьому словнику — Int, а Int не може бути nil, тож зберігати під ключем нічого. Ефект такий самий, як від removeValue(forKey:), тільки без повернення старого значення.

C#

dict["x"] у C# кидає KeyNotFoundException. У Swift повертається nil, тож аналог TryGetValue — це просто if let. А dict["x"] = nil — аналог dict.Remove("x").

Пастка

Якщо значення словника самі опціональні ([String: Int?]), то dict[key] = nil теж видалить ключ. Щоб справді зберегти nil як значення, пиши dict.updateValue(nil, forKey: key).

Ітерація

Swift
for (zone, lvl) in levels {
    print("\(zone): \(lvl)")
}
for zone in levels.keys.sorted() { print(zone) }
let allLevels = Array(levels.values)

keys і values — це легкі «погляди» на словник. Якщо потрібен масив, обгорни їх у Array(...). Порядок обходу не визначений і може змінюватися між запусками, тому для стабільного виведення сортуй ключі.

Корисні методи: mapValues, filter, merge(_:uniquingKeysWith:), Dictionary(grouping:by:) (аналог GroupBy).

Swift
let words = ["apple", "avocado", "banana", "blueberry", "cherry"]
let byLetter = Dictionary(grouping: words, by: { $0.first! })
// ["a": ["apple", "avocado"], "b": [...], "c": ["cherry"]]

Перевір себе

Обери відповідь — одразу побачиш, чи правильно, і пояснення.

1. Що надрукує цей код?

Swift
var original = [1, 2, 3]
var copy = original
copy.append(4)
print(original.count)

Масиви — value types: copy — окрема копія, і зміна не зачіпає original.

2. Що можна зробити з масивом, оголошеним через let?

let робить незмінною всю колекцію.

3. Що означає [String: Int]?

Це короткий запис Dictionary<String, Int>.

4. Що повертає array.first?

first і last безпечні — на порожньому масиві повертають nil. А array[0] на порожньому масиві — крах.

5. Що надрукує цей код?

Swift
var queue = ["intro", "a", "b", "boss"]
queue[1...2] = ["tutorial"]
print(queue)

Діапазон елементів можна замінити масивом будь-якої довжини.

6. Яке твердження неправильне?

Методи колекцій обчислюються одразу. Ліниву версію вмикають явно через .lazy.

7. Що надрукує цей код?

Swift
var tags: Set = ["new", "sale"]
tags.insert("sale")
print(tags.count)

У множині кожне значення лише один раз — дубль не додається.

8. Що станеться без слова Set у var tags = ["new", "sale"]?

Квадратні дужки без явного типу Swift вважає масивом.

9. Що мають уміти елементи множини?

Множина швидко знаходить елемент за хешем. Базові типи вже Hashable, а для власних структур компілятор генерує реалізацію.

10. Що поверне ["sword", "shield"].intersection(["shield", "bow"]) для множин?

intersection — те, що є в обох множинах. union — усе разом, subtracting — лише в першій.

11. Що станеться після levels["forest"] = nil для var levels: [String: Int]?

Присвоєння nil через сабскрипт видаляє ключ.

12. Що надрукує цей код?

Swift
var counts: [String: Int] = [:]
counts["tap", default: 0] += 1
counts["tap", default: 0] += 1
print(counts["tap"]!)

default: підставляє значення для відсутнього ключа, тож рахувати частоти зручно без перевірок.

Практика
  1. Порахуй частоту кожного слова в реченні у [String: Int], використовуючи default:.
  2. Дано два масиви ID гравців (сьогодні й учора). Знайди нових, тих, хто пішов, і тих, хто грав обидва дні, через Set.
  3. Покажи на прикладі, що зміна копії масиву не змінює оригінал, а зміна копії масиву класів змінює об'єкти. Чому так?
  4. Згрупуй масив (name: String, score: Int) за десятками очок через Dictionary(grouping:by:).
