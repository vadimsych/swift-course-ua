Методи

Методи екземпляра й типу, self, mutating-методи у value types і присвоєння self.

У книзі: methods

Методи екземпляра

Метод — функція, що належить типу. Методи можуть мати не лише класи, а й структури та перелічення. Для C#-розробника нове тут лише останнє: у C# enum методів не має (тільки через extension methods), а в Swift enum — повноцінний тип.

Swift
import Foundation

final class DownloadQueue {
    private(set) var pending: [URL] = []

    func enqueue(_ url: URL) {
        pending.append(url)
    }

    func clear() {
        pending.removeAll()
    }
}

let queue = DownloadQueue()
queue.enqueue(URL(string: "https://example.com/a.zip")!)
queue.clear()

Правила міток аргументів такі самі, як для функцій.

self

self — поточний екземпляр, як this у C#. Писати його явно потрібно в двох випадках: коли параметр затіняє властивість з тим самим ім'ям (найчастіше в ініціалізаторах і «сеттерах») і в escaping-замиканнях класів (урок 7):

Swift
import Foundation

struct Profile {
    var nickname: String
    mutating func update(nickname: String) {
        self.nickname = nickname.trimmingCharacters(in: .whitespaces)   // ліворуч — властивість
    }
}

Зміна value types у методах

Методи структур і перелічень за замовчуванням не можуть змінювати властивості, бо self у них — константа. Щоб дозволити зміну, метод позначають mutating:

Swift
struct Stamina {
    var current = 100

    mutating func spend(_ amount: Int) {
        current = max(0, current - amount)
    }
}

var stamina = Stamina()
stamina.spend(30)
stamina.spend(90)          // 0, а не від'ємне

let frozen = Stamina()
// frozen.spend(10)        // помилка: mutating-метод на let-константі

mutating — це інформація і для компілятора, і для читача: «цей метод змінює значення». Мутуючий метод не можна викликати на let-константі.

C#

У C# метод структури може мовчки змінити копію (класична пастка з List<MyStruct>[i].Mutate(), яка нічого не змінює в списку). У Swift компілятор чітко розрізняє мутуючі й немутуючі методи, а array[i].spend(10) працює правильно і змінює елемент масиву.

Присвоєння self у мутуючому методі

Мутуючий метод може замінити екземпляр цілком. Для enum це головний спосіб змінювати стан — наприклад, крок онбордингу, що вміє перейти до наступного:

Swift
enum OnboardingStep {
    case welcome, permissions, paywall, done

    mutating func advance() {
        self = switch self {
        case .welcome: .permissions
        case .permissions: .paywall
        case .paywall, .done: .done
        }
    }
}

var step = OnboardingStep.welcome
step.advance()   // .permissions

Методи типу

Методи, що викликаються на самому типі, позначаються static. У класах можна використати class func, щоб дозволити підкласам їх перевизначати.

Swift
struct Currency {
    let code: String
    let symbol: String

    static let supported: [Currency] = [
        Currency(code: "UAH", symbol: "₴"),
        Currency(code: "USD", symbol: "$"),
    ]

    static func find(code: String) -> Currency? {
        supported.first { $0.code == code }      // без префікса всередині static
    }

    func format(_ amount: Double) -> String {
        let known = Self.find(code: code) != nil  // Self — поточний тип
        return known ? "\(amount) \(symbol)" : "\(amount) \(code)"
    }
}

Currency.find(code: "UAH")?.format(99.5)   // "99.5 ₴"

Якщо результат методу (екземпляра чи типу) нормально ігнорувати — наприклад, insert повертає, чи вдалося вставити, — метод позначають @discardableResult, і компілятор не попереджатиме про невикористане значення.

У методі типу self посилається на сам тип, а не на екземпляр. Всередині методу типу інші статичні члени можна викликати без префікса. У методі екземпляра до статичних членів звертаються через ім'я типу або Self.

C#

static — як static у C#. class func — статичний метод, який підклас може перевизначити; у C# такого немає.

Перевір себе

Обери відповідь — одразу побачиш, чи правильно, і пояснення.

1. Чому тут помилка компіляції?

Swift
struct Counter {
    var value = 0
    func increment() { value += 1 }
}

Методи value types за замовчуванням не можуть змінювати self. mutating дає на це дозвіл.

2. Що означає self у методі екземпляра?

Явно self. пишуть, коли параметр має те саме ім'я, що й властивість, або в escaping-замиканнях класу.

3. Що надрукує цей код?

Swift
enum Step {
    case welcome, paywall, done
    mutating func advance() {
        self = switch self {
        case .welcome: .paywall
        case .paywall, .done: .done
        }
    }
}
var s = Step.welcome
s.advance()
s.advance()
print(s)

Перший виклик: .welcome → .paywall. Другий: .paywall → .done.

4. Чим class func відрізняється від static func у класі?

Обидва — методи типу. class дозволяє підкласам перевизначати, static — забороняє.

5. Що станеться, якщо викликати mutating-метод на let-константі структури?

Компілятор знає, що метод змінює значення, і не дає викликати його на константі.

Практика
  1. Зроби структуру Inventory з масивом предметів і методами add, remove(at:), sortByRarity(). Які з них мають бути mutating?
  2. Зроби enum PlaybackRate з сирими значеннями 0.5, 1.0, 1.5, 2.0 і mutating-метод faster(), що переходить до наступної швидкості й зупиняється на максимальній.
  3. Додай до Inventory статичну властивість maxSlots і статичний метод, що перевіряє, чи вміститься потрібна кількість предметів.
  4. Перевір, що відбудеться, якщо викликати mutating-метод на елементі масиву структур, на елементі словника і на let-константі.
