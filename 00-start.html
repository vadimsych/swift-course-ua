Як влаштований курс і що таке Swift

Перший урок: що за мова Swift, як вона співвідноситься з C#, які версії й режими мови існують, і швидка мапа синтаксису, щоб далі не спотикатися.

Як читати цей курс

Курс іде за розділами офіційної книги «The Swift Programming Language», але текст і приклади тут власні. Він розрахований на людину, яка вже добре знає C# і Unity, тож знайоме я згадую одним рядком, а на відмінностях зупиняюсь детально.

У тексті трапляються виноски:

  • C# — як те саме виглядає в C# чи Unity;
  • Пастка — де досвід з C# веде в оману;
  • Порада — практичні рекомендації;
  • Swift 6 — можливості останніх версій мови;
  • Практика — короткі задачі наприкінці уроку. Пиши їх у Xcode Playground або у файлі, який запускаєш командою swift file.swift.

Що таке Swift коротко

Swift — компільована мова зі статичною типізацією, яку Apple представила у 2014 році як заміну Objective-C. З 2015 року вона open source, працює на macOS, iOS, Linux, Windows, і навіть на серверах та вбудованих пристроях.

Головні ідеї мови:

  • Безпека за замовчуванням. Змінну не можна прочитати до ініціалізації, індекси масивів перевіряються, переповнення цілих чисел — помилка під час виконання, а не тихе «загортання». nil можливий тільки там, де тип явно це дозволяє.
  • Value types як основа. struct і enum — повноцінні типи з методами, протоколами й розширеннями. Стандартні Array, String, Dictionary — структури.
  • Пам'ять без GC. Об'єкти класів керуються підрахунком посилань (ARC), а не збирачем сміття.
  • Протоколи замість глибокого успадкування. Розширення протоколів дають реалізацію за замовчуванням, і більшість поведінки будується композицією.
  • Перевірка конкурентності компілятором. У режимі Swift 6 компілятор доводить відсутність data races між потоками.
C#

Найближча аналогія — сучасний C# з nullable reference types, records і async/await, але без GC і з набагато сильнішими struct та enum. Синтаксично Swift ближчий до Kotlin.

Версії й режими мови: що виставити в проєкті

У Swift є дві різні «версії», і їх легко сплутати:

  • версія компілятора — та, що прийшла з Xcode (зараз Swift 6.4 у Xcode 27);
  • режим мови (language mode) — набір правил, за якими компілятор перевіряє твій код: Swift 6, 5, 4.2 чи 4.

Практичний чекліст:

  1. Новий застосунок — режим Swift 6. У Xcode: Build Settings → Swift Language Version. У Swift Package: swiftLanguageModes: [.v6] у Package.swift.
  2. Старий код — можна лишити Swift 5 і вмикати нові перевірки поступово через Upcoming Features (у пакетах — .enableUpcomingFeature(...)).
  3. Великий проєкт — переводь по одному модулю: модулі з різними режимами нормально залежать один від одного.
  4. Мінімальна iOS — async/await і актори працюють з iOS 13, тож для сучасних застосунків обмежень немає.

Головна різниця між режимами 5 і 6 — перевірка data races: у режимі Swift 6 компілятор відмовиться збирати код, де змінюваний стан може використовуватися з кількох потоків без захисту. Більшість інших нових можливостей мови доступні в обох режимах.

Порада

Новий проєкт одразу починай у режимі Swift 6. Переводити старий код на сувору конкурентність набагато болючіше, ніж одразу писати правильно.

Мапа синтаксису для C#-розробника

Детально кожна тема буде у своєму уроці. Тут — щоб одразу читати чужий код.

Swift
// Точка входу — код верхнього рівня в main.swift або тип з @main, функція main() не потрібна
let maxLives = 3            // константа, як readonly local
var score = 0               // змінна
var nickname: String? = nil // опціонал, як string? з nullable

func damage(_ amount: Int, crit: Bool = false) -> Int {
    crit ? amount * 2 : amount
}
damage(10, crit: true)      // мітки аргументів — частина виклику

struct Vector2 {            // value type, копіюється
    var x: Double
    var y: Double
    var length: Double { (x * x + y * y).squareRoot() }
}

final class Enemy {         // reference type, ARC
    let name: String
    var hp: Int
    init(name: String, hp: Int) {
        self.name = name
        self.hp = hp
    }
}

enum LoadState {            // enum з асоційованими значеннями
    case idle
    case loading(progress: Double)
    case failed(Error)
}

protocol Damageable {       // як interface, але потужніший
    mutating func takeHit(_ amount: Int)
}

extension Int {             // розширення будь-якого типу
    var isEven: Bool { self % 2 == 0 }
}

let names = ["Ann", "Bob"]             // масив; словник — ["key": 1]
for name in names where name != "Bob" {
    print("Привіт, \(name)")            // інтерполяція рядків
}
let sorted = names.sorted { $0 > $1 }   // замикання з trailing-синтаксисом

if let nickname { print(nickname) }     // розгортання опціоналу
let length = nickname?.count ?? 0       // опціональний ланцюжок і ??

func firstOrNil<T>(_ items: [T]) -> T? { items.first }   // узагальнення

func loadProfile() async throws -> String {
    try await Task.sleep(for: .seconds(1))
    return "Vadim"
}

Кожен рядок цього фрагмента розібрано окремо: колекції — урок 4, цикли й if let — уроки 1 і 5, замикання — урок 7, класи й успадкування — уроки 9 і 13, enum — урок 8, протоколи — урок 23, узагальнення — урок 24, помилки (do-catch, try?, defer) — урок 17, конкурентність — урок 18.

Що одразу впадає в око:

C# Swift
var x = 5; / readonly var x = 5 / let x = 5
string? s var s: String?
int Foo(int a) func foo(a: Int) -> Int

interface protocol
extension methods (static class) extension будь-якого типу, з властивостями й протоколами
switch з break switch без провалювання, обов'язково вичерпний
Task<T>, async/await async/await, Task, актори

Playground і перший запуск

Найшвидший спосіб пробувати код:

  1. Xcode → File → New → Playground → Blank. Код виконується одразу, результати видно праворуч.
  2. Або Swift-файл у терміналі: swift hello.swift. Код верхнього рівня виконується зверху вниз, main() не потрібна.
  3. Для чогось більшого — swift package init --type executable і swift run.

print виводить у консоль, кілька аргументів розділяються пробілом:

Swift
print("HP:", 42, "з", 100)   // HP: 42 з 100
print("loading", terminator: "") // без переходу на новий рядок

Перевір себе

Обери відповідь — одразу побачиш, чи правильно, і пояснення.

1. Як радить читати уроки 30–36 (довідник)?

Довідник потрібен для уточнень, а не для читання від початку до кінця.

2. Яке твердження про Swift неправильне?

nil можна присвоїти лише опціоналу (String?). Тип без ? гарантовано має значення.

3. Чим головно відрізняється режим мови Swift 6 від Swift 5?

Більшість нових можливостей є в обох режимах. Головна різниця — сувора перевірка конкурентності. Модулі з різними режимами нормально залежать один від одного.

4. Де в Xcode задається режим мови для таргета?

Режим задається для кожного таргета окремо. У Swift Package — через swiftLanguageModes у Package.swift.

5. Як записати функцію, що приймає Int і повертає String?

Спочатку ім'я параметра, двокрапка й тип, а тип результату — після стрілки ->.

6. Що оголошує let, а що var?

У Swift заведено писати let усюди, де значення не змінюється.

7. Як найшвидше запустити один Swift-файл із терміналу?

Код верхнього рівня у файлі виконується зверху вниз, функція main() не потрібна.

Практика
  1. Створи Playground, оголоси структуру Item з назвою й ціною та клас Inventory з масивом предметів і методом add.
  2. Додай enum Rarity з варіантами common, rare, epic і поле rarity в Item.
  3. Виведи загальну вартість інвентарю. Не переймайся, якщо щось не компілюється — усе розберемо в наступних уроках.
