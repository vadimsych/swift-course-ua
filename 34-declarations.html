Довідник (за потреби) · урок 34

Довідник: оголошення

Коротка карта всіх видів оголошень — від імпорту й змінних до операторів. Більшість тем уже розібрані в попередніх уроках; тут — те, що корисно знати додатково.

У книзі: declarations

Код верхнього рівня

У файлі main.swift (або в скрипті) інструкції верхнього рівня виконуються як програма — це точка входу. У решті файлів верхній рівень може містити лише оголошення.

Альтернатива main.swift — тип з атрибутом @main і статичним методом main() (урок 35). Точка входу в програмі лише одна.

Блоки коду

{ інструкції } — використовуються в функціях, розгалуженнях тощо, створюють нову область видимості.

Імпорт

Swift
import Foundation
import struct SwiftUI.Color      // імпорт лише одного символу
import func Darwin.sqrt
@testable import PaywallKit      // доступ до internal у тестах
@preconcurrency import LegacySDK // м'якші перевірки Sendable для старого модуля

Імпорт окремого символу пишуть з видом оголошення: typealias, struct, class, enum, protocol, let, var, func. Перед import можна вказати рівень доступу (private import, internal import, public import), що визначає, чи видно залежність клієнтам модуля.

Оголошення констант

let ім'я: Тип = вираз. Локальній константі можна присвоїти значення пізніше, але один раз. Кортеж можна одразу розібрати: let (w, h) = size.

Оголошення змінних

Форма визначає вид змінної:

Збережені змінні й властивості

var ім'я: Тип = вираз — з ініціалізатором або без (тоді тип обов'язковий і значення має з'явитися до використання).

Обчислювані змінні й властивості

Swift
var ім'я: Тип {
    get { ... }
    set(новеІм'я) { ... }    // необов'язковий
}

Можуть бути глобальними, локальними чи властивостями. Геттер може бути async і throws: var data: Data { get async throws { ... } }.

Спостерігачі

Swift
var ім'я: Тип = вираз {
    willSet(нове) { ... }
    didSet(старе) { ... }
}

Спостерігачі не спрацьовують під час init і не викликаються повторно, якщо в didSet присвоїти нове значення.

Властивості типу

static var/static let, а в класах ще class var (тільки обчислювані, можна перевизначати в підкласах).

Псевдоніми типів

Swift
typealias Bag = Set                          // псевдонім generic-типу без параметрів: Bag<String>
typealias Handler = (Result<Data, Error>) -> Void
typealias StringMap<Value> = [String: Value]    // generic-псевдонім
typealias IntKeyed<Value> = [Int: Value]       // generic-псевдонім

Generic-псевдонім може звузити параметри: typealias HashBox<T: Hashable> = Box<T> прийме лише Hashable-типи, хоча сам Box таких обмежень не має.

Оголошення функцій

Swift
func ім'я<параметри типу>(параметри) async throws -> Результат where обмеження {
    інструкції
}

Імена параметрів

Кожен параметр має мітку аргументу й ім'я параметра: func move(from start: Int). Якщо вказано одне ім'я — воно і є міткою; _ прибирає мітку.

Модифікатори параметрів

  • inout — функція може змінити змінну викликача; при виклику пишуть &. Одну змінну не можна передати у два inout одночасно (урок 27).
  • borrowing — функція тимчасово отримує доступ до значення, не забираючи його. Копіювати його всередині явно не можна без copy.
  • consuming — функція стає власником значення. Для noncopyable-типів після виклику значення у викликача більше немає; для копійованих викликач може віддати власну копію.
Swift
func store(_ token: consuming SessionToken) { ... }
func inspect(_ token: borrowing SessionToken) -> String { ... }

borrowing і consuming здебільшого потрібні для noncopyable-типів і для оптимізації копіювань. За замовчуванням параметри функцій поводяться як borrowing, а параметри ініціалізаторів — як consuming.

Особливі види параметрів

  • _ замість імені — параметр ігнорується в тілі;
  • variadic Тип... — нуль чи більше значень, усередині масив; параметр після нього має мати мітку;
  • значення за замовчуванням = вираз — обчислюється при кожному виклику, в контексті виклику для макросів на кшталт #line.

Особливі види методів

  • mutating — може змінювати self у value type;
  • nonmutating — сеттер value type, що не змінює self (наприклад, записує в сховище за посиланням);
  • override — перевизначає член суперкласу;
  • static/class — метод типу; class дозволяє перевизначення.

Методи зі спеціальними іменами

  • callAsFunction — екземпляр можна викликати як функцію:
Swift
struct Multiplier {
    let factor: Int
    func callAsFunction(_ x: Int) -> Int { x * factor }
}
let triple = Multiplier(factor: 3)
triple(7)   // 21
  • dynamicallyCall(withArguments:) і dynamicallyCall(withKeywordArguments:) — для типів з @dynamicCallable;
  • subscript(dynamicMember:) — для типів з @dynamicMemberLookup (урок 35).

Throwing-функції

throws або throws(Тип) перед ->; виклик потребує try. Не-throwing функцію можна передати туди, де очікують throwing, а навпаки — ні.

Rethrowing-функції

rethrows — функція кидає помилки лише з переданого їй замикання. Якщо замикання не кидає, try при виклику не потрібен (так працює filter).

Асинхронні функції

async — функцію можна призупиняти; виклик через await. Синхронну функцію можна передати туди, де очікують асинхронну.

Функції, що не повертаються

Тип результату Never означає, що функція ніколи не повертає керування: fatalError, preconditionFailure, нескінченний цикл. Компілятор знає це і, наприклад, не вимагає return після виклику в guard-гілці.

Оголошення перелічень

Варіанти будь-яких типів

Swift
enum Shape {
    case circle(radius: Double)
    case rect(width: Double, height: Double)
    indirect case group([Shape], name: String = "")
}
  • Асоційовані значення можуть мати мітки і значення за замовчуванням.
  • Варіант з асоційованими значеннями можна використовувати як функцію: [1.0, 2.0].map(Shape.circle).
  • indirect — для рекурсивних варіантів (або для всього enum).

Варіанти з сирими значеннями

enum E: RawType { case a = literal } — сирий тип відповідає одному з протоколів літералів; enum автоматично отримує RawRepresentable з rawValue і init?(rawValue:). Варіанти без явного значення: для чисел — +1 від попереднього, для рядків — ім'я варіанта.

Звертання до варіантів

Тип.варіант або .варіант, якщо тип відомий. Зіставлення — через switch, if case тощо (урок 36).

Оголошення структур

struct Ім'я<параметри>: протоколи where обмеження { члени }. Структура — value type: копіюється, let-екземпляр повністю незмінний, автоматичні ініціалізатори (за замовчуванням і memberwise). Не можна успадковувати.

Оголошення класів

class Ім'я<параметри>: Суперклас, протоколи { члени }. Reference type: успадкування (один суперклас), deinit, приведення типів, ARC. Має щонайменше один designated-ініціалізатор (або отримує його автоматично). Модифікатори: final, open.

Оголошення акторів

actor Ім'я: протоколи { члени }. Reference type, що захищає свій стан від одночасного доступу. Без успадкування; автоматично Sendable (урок 18).

Оголошення протоколів

Swift
protocol Ім'я: успадковані протоколи {
    var властивість: Тип { get set }
    static var типова: Тип { get }
    func метод(параметри) -> Тип
    mutating func змінити()
    init(параметри)
    init?(параметри)
    subscript(i: Int) -> Тип { get }
    associatedtype Елемент: Обмеження = ЗаЗамовчуванням
}

Обмеження й особливості протоколів:

  • : AnyObject робить протокол доступним лише для класів і акторів, а : SomeClass — лише для підкласів цього класу;
  • optional-вимоги можливі тільки в @objc-протоколах;
  • статичну вимогу (static var, static func) може задовольнити варіант enum: case none реалізує static var none: Self;
  • статичні вимоги клас реалізує через static або class;
  • протокол можна вкласти лише в не-generic тип.

Вимоги-властивості

Лише var з { get } або { get set }. Протокол не визначає, збережена чи обчислювана.

Вимоги-методи

Сигнатура без тіла, без значень параметрів за замовчуванням. Можуть бути static, mutating, async, throws.

Вимоги-ініціалізатори

Реалізуються в класах як required (якщо клас не final). Вимогу init (не-failable) можна задовольнити лише звичайним ініціалізатором або init!; вимогу init? — будь-яким: init?, init! чи звичайним.

Вимоги-сабскрипти

Вказують { get } або { get set }.

Асоційовані типи

associatedtype з необов'язковими обмеженнями, where і типом за замовчуванням. Протокол-нащадок може обмежити асоційований тип батьківського через where у своєму оголошенні.

Оголошення ініціалізаторів

init, init?, init!, з модифікаторами convenience, required, override, а також async і throws. Ініціалізатор класу мусить ініціалізувати власні властивості до super.init. Ініціалізатор value type може присвоїти self цілком.

Failable-ініціалізатори

init? повертає nil через return nil. Може делегувати іншому failable чи звичайному; підклас може перевизначити failable звичайним, але не навпаки.

Оголошення деініціалізаторів

deinit { } — лише в класах, акторах і noncopyable-структурах і enum. Без параметрів, викликається автоматично.

Оголошення розширень

extension Тип: протоколи where умови { члени }. Додає обчислювані властивості, методи, ініціалізатори, протоколи. Збережені властивості й перевизначення додати не можна (урок 22).

Умовна відповідність

extension Array: Summable where Element: Summable { } — відповідність лише для частини конкретизацій generic-типу.

Перевизначені реалізації в generic-контексті

Підступ умовної відповідності: якщо в обмеженому розширенні дати «кращу» реалізацію методу, generic-код її не побачить і викличе базову. Різну поведінку надійніше робити окремими протоколами.

Відповідність не може бути надлишковою

Тип може відповідати протоколу лише один раз. Не можна мати дві умовні відповідності одному протоколу з різними умовами, навіть якщо вони не перетинаються:

Swift
extension Box: Describable where Item: Comparable { }
// extension Box: Describable where Item: Identifiable { }   // помилка: друга відповідність

Якщо потрібна різна поведінка, роблять одну відповідність з мінімальною умовою, а різницю реалізують через перевантажені методи в обмежених розширеннях.

Якщо компілятор скаржиться на неоднозначну відповідність батьківському протоколу, оголоси її явно з найзагальнішою умовою.

Оголошення сабскриптів

Swift
subscript(параметри) -> Тип {
    get { ... }
    set(нове) { ... }
}

Параметри без міток за замовчуванням. Геттер може бути async/throws (без сеттера). Можуть бути generic і перевантаженими.

Сабскрипти типу

static subscript (або class subscript у класах) — сабскрипт на самому типі.

Оголошення макросів

Swift
@freestanding(expression)
macro ім'я(параметри) -> Тип = #externalMacro(module: "Plugin", type: "Impl")

@attached(member, names: named(reset))
macro Resettable() = #externalMacro(module: "Plugin", type: "ResettableMacro")

Атрибут задає вид і ролі (урок 19). Тіло — посилання на реалізацію в плагіні компілятора або розгортання іншого макросу.

Оголошення операторів

Swift
prefix operator √
postfix operator °
infix operator <=> : ComparisonPrecedence

Оголошення лише вводить символ і (для infix) групу пріоритету; реалізація — окремою функцією (урок 29).

Оголошення груп пріоритетів

Swift
precedencegroup ExponentiationPrecedence {
    higherThan: MultiplicationPrecedence
    lowerThan: BitwiseShiftPrecedence
    associativity: right
    assignment: false
}
  • higherThan/lowerThan — відношення з іншими групами (lowerThan — лише щодо груп з інших модулів);
  • associativity — left, right або none (за замовчуванням none);
  • групи не утворюють єдиної лінійної шкали: дві групи без явного зв'язку між собою не можна змішувати без дужок;
  • assignment: true — оператор поводиться як присвоєння в опціональних ланцюжках.

Модифікатори оголошень

  • class — член типу класу, що може перевизначатися.
  • dynamic — виклики завжди йдуть через динамічну диспетчеризацію Objective-C (для KVO, swizzling).
  • final — заборона перевизначення чи успадкування.
  • lazy — ліниве обчислення збереженої властивості.
  • optional — необов'язкова вимога в @objc-протоколі.
  • required — ініціалізатор, обов'язковий для всіх підкласів.
  • static — член типу (не перевизначається).
  • unowned, unowned(safe), unowned(unsafe) — посилання без утримання; unsafe вимикає перевірку в рантаймі.
  • weak — слабке посилання, обнуляється при звільненні.
  • nonisolated — член, вільний від ізоляції актора; nonisolated(unsafe) — вимикає перевірки ізоляції для змінної під твою відповідальність.

Рівні доступу

open, public, package, internal, fileprivate, private, а також форми для сеттерів: private(set) тощо. Урок 28.

Перевір себе

Обери відповідь — одразу побачиш, чи правильно, і пояснення.

1. Де інструкції верхнього рівня (наприклад, print("hi") поза будь-якою функцією) виконуються як програма?

Лише main.swift чи скрипт можуть містити виконувані інструкції верхнього рівня; в інших файлах там дозволені тільки оголошення.

2. Що надрукує цей код?

Swift
let x = 1
do {
    let x = 2
    print(x)
}
print(x)

Блок { } створює нову область видимості, тож внутрішній x існує лише в ньому.

3. Що робить рядок import struct SwiftUI.Color?

Імпорт окремого символу пишуть з видом оголошення (struct, func, class тощо) і повним шляхом.

4. Чому тут помилка компіляції?

Swift
func run() {
    let label: String
    label = "Pro"
    label = "Free"
    print(label)
}
run()

Відкладене присвоєння let дозволене, проте друге присвоєння — помилка.

5. Що надрукує цей код?

Swift
struct Counter {
    var value: Int {
        didSet { print("didSet \(value)") }
    }
    init() { value = 1 }
}
func run() {
    var c = Counter()
    c.value = 5
}
run()

Спостерігачі не спрацьовують під час init, тому друкується лише присвоєння 5.

6. Яке твердження про typealias неправильне?

Псевдонім — лише інше ім'я наявного типу. Price і Int — той самий тип, тож значення взаємозамінні.

7. Що надрукує цей код?

Swift
struct Discount {
    let percent: Int
    func callAsFunction(_ price: Int) -> Int { price - price * percent / 100 }
}
let half = Discount(percent: 50)
print(half(80))

Метод callAsFunction дозволяє викликати екземпляр як функцію: half(80) — це half.callAsFunction(80).

8. filter оголошено як rethrows. Чому [1, 2, 3].filter { $0 > 1 } не потребує try?

Якщо передане замикання не кидає, виклик rethrows-функції теж не кидає, і try не потрібен.

9. Що надрукує цей код? Зверни увагу: у guard-гілці немає return.

Swift
func fail(_ message: String) -> Never {
    fatalError(message)
}
func price(_ raw: String) -> Int {
    guard let value = Int(raw) else { fail("bad") }
    return value
}
print(price("12"))

fail повертає Never, тож компілятор знає, що з else-гілки керування не повернеться. Для "12" guard проходить.

10. Що надрукує цей код?

Swift
enum Level: Int {
    case low = 1, medium, high = 10, max
}
print(Level.medium.rawValue, Level.max.rawValue)

Варіант без явного числового значення отримує +1 від попереднього: medium = 2, max = 11.

11. Яке твердження про структури неправильне?

Успадкування є лише в класів; структури не успадковуються.

12. Що надрукує цей код?

Swift
class Plan {
    var name = "Free"
}
func run() {
    let a = Plan()
    let b = a
    b.name = "Pro"
    print(a.name)
}
run()

Клас — reference type: a і b вказують на один об'єкт, а let фіксує лише посилання.

13. Яке твердження про актори правильне?

Актори не підтримують успадкування й автоматично відповідають Sendable.

14. Що надрукує цей код?

Swift
protocol HasDefault {
    static var none: Self { get }
}
enum Filter: HasDefault {
    case none, recent
}
print(Filter.none)

Статичну вимогу static var none: Self може задовольнити варіант enum case none.

15. Що надрукує цей код?

Swift
struct Percent {
    let value: Int
    init?(_ value: Int) {
        if value < 0 || value > 100 { return nil }
        self.value = value
    }
}
print(Percent(150) == nil, Percent(40)?.value ?? -1)

init? повертає nil через return nil, тож Percent(150) — nil, а Percent(40) успішний.

16. Де можна оголосити deinit?

Звичайні копійовані структури й enum не мають deinit; він є в класах, акторах і noncopyable-типах.

17. Чому тут помилка компіляції?

Swift
protocol Describable {}
struct Box<Item> { let item: Item }
extension Box: Describable where Item: Comparable {}
extension Box: Describable where Item: Hashable {}

Відповідність не може бути надлишковою: для різної поведінки роблять одну відповідність і перевантаження в обмежених розширеннях.

18. Що надрукує цей код? Зверни увагу на виклик сабскрипта без міток.

Swift
struct Grid {
    var cells = [0, 0, 0, 0]
    subscript(row: Int, col: Int) -> Int {
        get { cells[row * 2 + col] }
        set { cells[row * 2 + col] = newValue }
    }
}
func run() {
    var g = Grid()
    g[1, 0] = 7
    print(g.cells)
}
run()

Параметри сабскрипта за замовчуванням не мають міток аргументів; індекс 1 * 2 + 0 = 2.

19. Що задає атрибут на кшталт @freestanding(expression) чи @attached(member, names: ...) перед оголошенням macro?

Атрибут описує вид і ролі; реалізацію вказують після = через #externalMacro.

20. Що надрукує цей код?

Swift
prefix operator √
prefix func √ (value: Double) -> Double { value.squareRoot() }
print(√16.0)

prefix operator лише оголошує символ, а реалізацію дає окрема функція prefix func.

21. Що надрукує цей код?

Swift
precedencegroup PowerPrecedence {
    higherThan: MultiplicationPrecedence
    associativity: right
}
infix operator ** : PowerPrecedence
func ** (base: Int, exp: Int) -> Int {
    var result = 1
    for _ in 0..<exp { result *= base }
    return result
}
print(2 ** 3 ** 2)

Права асоціативність групує 2 ** (3 ** 2) = 2 ** 9 = 512.

22. Який модифікатор вимикає перевірки ізоляції для змінної під твою відповідальність?

nonisolated(unsafe) знімає перевірки ізоляції; unowned(unsafe) стосується посилань без утримання, а не конкурентності.

Практика
  1. Зроби тип з callAsFunction, що форматує ціну, і виклич його як функцію.
  2. Напиши функцію, що приймає consuming noncopyable-значення, і переконайся, що компілятор забороняє використання після виклику.
  3. Оголоси власний оператор ** для піднесення до степеня з правою асоціативністю і пріоритетом вище за множення.
  4. Спробуй оголосити дві умовні відповідності одному протоколу й прочитай помилку. Перероби рішення на одну відповідність.
