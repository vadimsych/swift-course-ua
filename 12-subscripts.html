Сабскрипти

Як дати своєму типу доступ через квадратні дужки: синтаксис, кілька параметрів, перевантаження і сабскрипти типу.

У книзі: subscripts

Синтаксис

Сабскрипт дозволяє звертатися до значення через instance[index], як до масиву чи словника. Оголошується ключовим словом subscript, схоже на обчислювану властивість з параметрами:

Swift
struct Spreadsheet {
    private var cells: [String: String] = [:]

    subscript(column: Character, row: Int) -> String {
        get {
            cells["\(column)\(row)"] ?? ""
        }
        set {
            cells["\(column)\(row)"] = newValue.isEmpty ? nil : newValue
        }
    }
}

var sheet = Spreadsheet()
sheet["B", 3] = "Revenue"
print(sheet["B", 3])   // Revenue
print(sheet["Z", 9])   // "" — порожня клітинка

Як і в обчислюваних властивостей, сеттер отримує newValue (або власне ім'я), а сабскрипт лише для читання пишеться без get { }:

Swift
struct Translations {
    private let table: [String: String]
    init(_ table: [String: String]) { self.table = table }

    subscript(key: String) -> String {
        table[key] ?? key            // немає перекладу — показуємо ключ, щоб помітити на QA
    }
}

let uk = Translations(["paywall.title": "Отримай Pro"])
uk["paywall.title"]   // "Отримай Pro"
uk["paywall.cta"]     // "paywall.cta"

Використання

Сабскрипт підходить, коли тип за змістом — колекція, контейнер або відображення ключів на значення. Стандартна бібліотека використовує їх в Array (за індексом), Dictionary (за ключем, з опціональним результатом), String (за String.Index чи діапазоном).

Зверни увагу на словник: його сабскрипт повертає Value?, бо ключа може не бути, і так само приймає Value? у сеттері, щоб присвоєння nil видаляло ключ. Свої сабскрипти теж можна проєктувати з опціональним результатом.

C#

Це індексатори (this[int i]), і перевантаження, необов'язкові параметри й params там теж є. Справжні відмінності: параметри сабскрипта можуть мати мітки (list[safe: 3]), бувають статичні сабскрипти на самому типі, а геттер може бути async/throws.

Можливості сабскриптів

Сабскрипт поводиться майже як метод з особливим синтаксисом виклику, з кількома відмінностями від функцій:

функція сабскрипт
мітки аргументів за замовчуванням є немає — пишуть явно: subscript(safe i: Int)
inout-параметри можна не можна
variadic і значення за замовчуванням можна можна
перевантаження за типами й мітками так так
async/throws так лише в геттері
Swift
struct Playlist {
    var tracks: [String]

    subscript(index: Int) -> String { tracks[index] }

    subscript(safe index: Int) -> String? {          // мітка задана явно
        tracks.indices.contains(index) ? tracks[index] : nil
    }

    subscript(titled prefix: String) -> [String] {   // перевантаження за міткою й типом
        tracks.filter { $0.hasPrefix(prefix) }
    }
}

let mix = Playlist(tracks: ["Intro", "Interlude", "Outro"])
mix[0]               // "Intro"
mix[safe: 10]        // nil замість краху
mix[titled: "In"]    // ["Intro", "Interlude"]
Порада

Класичне розширення, яке є майже в кожному iOS-проєкті: swift extension Collection { subscript(safe index: Index) -> Element? { indices.contains(index) ? self[index] : nil } }

Сабскрипти можуть бути throws і async (тільки геттер), тоді звернення пишуть через try/await.

Сабскрипти типу

Сабскрипт можна оголосити на самому типі через static (або class у класах, щоб дозволити перевизначення):

Swift
enum StatusIcon {
    private static let icons = ["🔴", "🟠", "🟡", "🟢"]

    static subscript(health percent: Int) -> String {
        let index = min(max(percent, 0), 99) / 25
        return icons[index]
    }
}

StatusIcon[health: 80]   // "🟢"
StatusIcon[health: 10]   // "🔴"

Перевір себе

Обери відповідь — одразу побачиш, чи правильно, і пояснення.

1. Що таке сабскрипт?

Сабскрипт оголошують словом subscript, і він працює як обчислювана властивість з параметрами.

2. Як викликати subscript(safe index: Int) -> String??

Параметри сабскрипта за замовчуванням без міток, тож мітку safe задано явно — і її пишуть при виклику.

3. Яке твердження неправильне?

inout-параметри в сабскриптах не дозволені. Решта — правда.

4. Що надрукує цей код?

Swift
struct Translations {
    let table: [String: String]
    subscript(key: String) -> String { table[key] ?? key }
}
let uk = Translations(table: ["hi": "привіт"])
print(uk["bye"])

Ключа немає, тож ?? повертає сам ключ.

Практика
  1. Зроби структуру TicTacToeBoard з сабскриптом [row, column], що повертає Character?, і precondition, що перевіряє межі.
  2. Додай до дошки сабскрипт [row: Int], що повертає весь рядок як масив.
  3. Зроби тип Localization зі статичним сабскриптом Localization["key"], що повертає рядок зі словника або сам ключ, якщо перекладу немає.
  4. Реалізуй безпечний сабскрипт [safe:] для Collection і перевір його на масиві й на рядку.
