Мова крок за кроком · урок 03

Рядки й символи

String і Character у Swift: літерали, інтерполяція, Unicode, чому не можна написати text[3], підрядки, порівняння і представлення в UTF-8/UTF-16.

У книзі: stringsandcharacters

Рядкові літерали

Звичайний літерал — у подвійних лапках. Багаторядковий — між потрійними лапками, кожна на окремому рядку. Перенесення одразу після відкривальних і перед закривальними лапками в текст не входять; якщо потрібен порожній рядок на початку чи в кінці, залиш порожній рядок усередині літерала:

Swift
let greeting = "Привіт"

let help = """
    Керування:
      WASD — рух
      Space — стрибок
    """

У багаторядковому літералі відступ закривальних лапок задає, скільки пробілів обрізати з кожного рядка. Тому вище текст починається з «Керування», а «WASD» має два пробіли відступу. Рядок не може бути відступлений менше, ніж закривальні лапки.

Щоб розбити довгий рядок у коді, але не додавати перенесення в сам текст, рядок закінчують зворотною косою:

Swift
let long = """
    Це один рядок, \
    хоч у коді їх два.
    """

Спецсимволи

\0, \\, \t, \n, \r, \", \', а також Unicode-скаляр у форматі \u{n}, де n — від 1 до 8 шістнадцяткових цифр:

Swift
let euro = "\u{20AC}"         // €
let flagUA = "\u{1F1FA}\u{1F1E6}"  // 🇺🇦

У багаторядковому літералі лапки " можна писати без екранування. Щоб усередині був сам """, екрануй хоча б одну з лапок (\""") або візьми розширений роздільник #"""…"""#.

Розширені роздільники

Якщо рядок містить багато \ або ", його обрамлюють символами #. Тоді спецпослідовності не обробляються, поки в них не додано стільки ж #:

Swift
let regexText = #"\d+\.\d+"#          // бекслеші як є
let quote = #"Він сказав "привіт""#
let path = #"C:\Games\\#(folderName)"#   // \#( ) — інтерполяція, решта бекслешів як є
C#

Аналог — verbatim-рядки @"..." і raw string literals """...""" з C# 11. Інтерполяція в розширеному рядку пишеться як \#(value).

Порожній рядок

Swift
var log = ""
var log2 = String()
if log.isEmpty { print("порожньо") }

Змінність рядків

Змінність визначає let/var, а не окремий клас:

Swift
var title = "Рівень"
title += " 1"           // ок
let fixed = "Меню"
// fixed += "!"         // помилка компіляції
C#

Немає пари string/StringBuilder. var String уже змінний і ефективно дописується, тому += у циклі не створює квадратичної кількості копій, як у C#.

Рядки — значення

String — структура. При присвоєнні чи передачі у функцію отримувач має свою копію, і її зміна не впливає на оригінал. Фізично копіювання відкладене (copy-on-write): буфер дублюється лише тоді, коли одну з копій змінюють. Тож передача рядків дешева.

Swift
var a = "abc"
var b = a
b += "d"
print(a, b)   // abc abcd

Символи

Character — один видимий символ. Рядок — колекція символів, тож до нього застосовні всі методи колекцій:

Swift
let password = "Swift2026!"
let digits = password.filter(\.isNumber)              // "2026"
let hasUpper = password.contains(where: \.isUppercase) // true
let initials = "Taylor Swift".split(separator: " ").compactMap(\.first)  // ["T", "S"]
let fromChars = String(initials)                        // "TS"

Літерал з одного символу стає Character, якщо вказати тип: let separator: Character = "|".

Конкатенація

Swift
let a = "Game"
let b = "Over"
var text = a + " " + b
text += "!"
text.append(Character("?"))

Символ не можна дописати до Character — тільки до String.

Практична дрібниця: склеюючи кілька багаторядкових блоків через +, перевір, чи є між ними перенос — кінцевий перенос перед закривальними лапками в текст не потрапляє, тому блоки можуть «злипнутися» в один рядок.

Інтерполяція

\(вираз) усередині рядка:

Swift
let coins = 120
let price = 45
print("Після покупки лишиться \(coins - price) монет")

Вираз усередині \( ) у звичайному однорядковому літералі має вміститися в один рядок і не містити «голого» \; у багаторядковому літералі інтерполяцію можна розбивати на кілька рядків. У рядку з розширеним роздільником #"..."# інтерполяція пишеться як \#(...), а звичайне \(x) лишається просто текстом. Інтерполяцію можна налаштувати для власних типів через протокол CustomStringConvertible (властивість description) — аналог ToString().

Unicode

Тут Swift сильно відрізняється від C#.

Скаляри

String побудований з Unicode-скалярів — 21-бітних кодів (U+0000…U+D7FF і U+E000…U+10FFFF). Сурогатні пари, як у UTF-16 C#, на цьому рівні не існують.

Розширені кластери графем

Character — це не один скаляр, а розширений кластер графем: послідовність скалярів, яку людина сприймає як один символ.

Swift
let thumbs: Character = "\u{1F44D}\u{1F3FD}"  // 👍 + модифікатор тону шкіри
// два скаляри, але один символ: 👍🏽

let family = "👨‍👩‍👧"     // кілька емодзі, склеєних ZWJ, — один Character

Підрахунок символів

Типове завдання — обмеження довжини нікнейма «до 12 символів». Яку довжину рахувати?

Swift
let nick = "Олег👩‍💻🇺🇦"

nick.count               // 6 — символи, як їх бачить людина
nick.unicodeScalars.count // 9 — Unicode-скаляри
nick.utf16.count         // 13 — як string.Length у C# чи в JavaScript
nick.utf8.count          // 27 — байти в UTF-8

func isValidNickname(_ s: String) -> Bool {
    (3...12).contains(s.count)        // для інтерфейсу рахуємо символи
}

Для правил, які бачить користувач, бери count. Для обмежень бекенду чи бази даних, де ліміт у байтах або в UTF-16 одиницях, — відповідне представлення. Розбіжність між ними — часта причина багів «на сервері обрізало емодзі навпіл».

count не зберігається в рядку, а обчислюється: щоб знайти межі символів, рядок треба пройти повністю (O(n)). У гарячому циклі краще порахувати один раз.

C#

string.Length у C# рахує UTF-16 одиниці: "🇺🇦".Length == 4. У Swift "🇺🇦".count == 1. Еквівалент C#-поведінки — utf16.count.

Доступ і зміна

Індекси рядка

Через змінну ширину символів рядок не можна індексувати цілим числом. Позиції описує тип String.Index, і його отримують від самого рядка. Найчастіше індекси знаходять пошуком, а не обчислюють вручну:

Swift
/// "Ivan Petrenko" → "Ivan P."
func shortName(_ full: String) -> String {
    guard let space = full.firstIndex(of: " ") else { return full }
    let surnameStart = full.index(after: space)
    guard surnameStart < full.endIndex else { return full }
    return full[..<space] + " " + String(full[surnameStart]) + "."
}

/// Обрізає рядок до n символів і додає три крапки.
func truncated(_ text: String, to n: Int) -> String {
    guard let cut = text.index(text.startIndex, offsetBy: n, limitedBy: text.endIndex),
          cut < text.endIndex else { return text }
    return text[..<cut] + "…"
}

Що тут важливо:

  • startIndex — перший символ, endIndex — позиція після останнього. Звернення text[text.endIndex] — крах, як і index(after: endIndex). У порожнього рядка startIndex == endIndex.
  • index(after:), index(before:), index(_:offsetBy:) рухають індекс; варіант з limitedBy: повертає nil замість краху.
  • startIndex, endIndex, index(after:) і index(_:offsetBy:) є в будь-якій Collection; index(before:) — лише у двонаправлених колекціях (BidirectionalCollection: масиви, рядки), а в Set і Dictionary його немає.
  • Індекс, отриманий від одного рядка, не можна використовувати з іншим.
Пастка

text[3] не скомпілюється — і це не забаганка, а захист від розрізання символу навпіл. Якщо треба часто звертатися за номером, перетвори в масив: let chars = Array(text), і тоді chars[3] працює за O(1).

Вставка й видалення

Swift
var tag = "v2026"
tag.insert("-", at: tag.index(tag.startIndex, offsetBy: 1))   // "v-2026"
tag.insert(contentsOf: "beta", at: tag.endIndex)               // "v-2026beta"
tag.remove(at: tag.startIndex)                                 // прибрали "v"
if let r = tag.firstRange(of: "beta") {
    tag.replaceSubrange(r, with: "rc")                         // "-2026rc"
}
tag.removeFirst()                                              // "2026rc"

Ці методи є в усіх типах, що реалізують RangeReplaceableCollection: String, Array, Data тощо.

Підрядки

Результат зрізу (text[a..<b], prefix, split) — це Substring, а не String. Він ділить пам'ять з оригіналом, тому створюється миттєво. Але поки живе Substring, живе й увесь вихідний рядок.

Swift
let line = "player:42"
let parts = line.split(separator: ":")   // [Substring]
let name = String(parts[0])              // копія в окремий String для зберігання

Правило: Substring — для короткочасної роботи, а для зберігання (у властивостях, довгоживучих структурах) перетворюй у String. Обидва типи реалізують StringProtocol, тож більшість методів однакові.

Порівняння

Рівність

== порівнює рядки за змістом (канонічною еквівалентністю), а не за байтами. Це помітно, коли текст надходить з різних джерел. Наприклад, macOS-файлова система й веб-форма можуть закодувати ту саму літеру «й» по-різному — одним скаляром або «и» + комбінований знак:

Swift
let fromFileSystem = "Андрі\u{438}\u{306}"     // и + бреве
let fromForm = "Андрі\u{439}"                 // й одним скаляром
fromFileSystem == fromForm                     // true
fromFileSystem.utf8.count == fromForm.utf8.count   // false — байти різні

А от літери з різних алфавітів, навіть однакові на вигляд, рівними не будуть — це важливо для перевірки логінів і доменів.

Порівняння чутливе до регістру й не залежить від локалі. Для порівняння без урахування регістру — a.lowercased() == b.lowercased() або Foundation-методи (localizedCaseInsensitiveCompare).

Префікс і суфікс

Swift
let file = "level_03.json"
file.hasPrefix("level_")   // true
file.hasSuffix(".json")    // true

Вони теж порівнюють посимвольно з урахуванням еквівалентності.

Представлення в Unicode-кодуваннях

Рядок дає три «погляди» на свій вміст:

Swift
let s = "Ї🇺🇦"
Array(s.utf8)            // байти UTF-8: [208, 135, 240, 159, ...]
Array(s.utf16)           // одиниці UTF-16, як в C# string
s.unicodeScalars.map { $0.value }   // коди скалярів
  • utf8 — UInt8, для запису у файли й мережу.
  • utf16 — UInt16, для сумісності з NSString, JavaScript і C#.
  • unicodeScalars — Unicode.Scalar з властивістю value: UInt32 і properties (категорія, чи це емодзі тощо).

Перевір себе

Обери відповідь — одразу побачиш, чи правильно, і пояснення.

1. Що визначає, скільки пробілів обріжеться з кожного рядка в літералі """..."""?

Жоден рядок не може мати меншого відступу, ніж закривальні лапки.

2. Що надрукує цей код?

Swift
let name = "Ann"
print(#"Hi \(name)"#)

У рядку з розширеним роздільником #"..."# інтерполяція пишеться як \#(name), а звичайне \(name) лишається текстом.

3. Як перевірити, що рядок порожній?

isEmpty — стандартна властивість будь-якої колекції, зокрема рядка.

4. Що станеться з let title = "Меню"; title += "!"?

Змінність рядка визначає let/var: let-рядок змінювати не можна.

5. Що надрукує цей код?

Swift
var a = "abc"
var b = a
b += "d"
print(a)

String — value type: b — окрема копія.

6. Що надрукує цей код?

Swift
print("Swift2026!".filter(\.isNumber))

Рядок — колекція символів, тож до нього застосовні filter та інші методи колекцій.

7. Що з цього не скомпілюється?

Character — один символ, дописувати до нього не можна. Дописують до String.

8. Як вставити значення змінної coins у рядок?

Інтерполяція — \(вираз) усередині звичайного рядка.

9. Що таке Character у Swift?

Емодзі з модифікатором тону чи прапор — це кілька скалярів, але один Character.

10. Що поверне "🇺🇦".count?

count рахує символи, як їх бачить людина. Прапор — один символ.

11. Чому text[3] не компілюється для String?

Знайти «третій символ» за O(1) неможливо. Для частого доступу за номером рядок перетворюють у масив: Array(text).

12. Що правда про Substring?

Поки живий зріз, живий і весь оригінальний рядок.

13. Як порівнює рядки оператор ==?

Це канонічна еквівалентність. Регістр при цьому враховується.

14. Яку довжину брати, якщо бекенд обмежує поле кількістю байтів у UTF-8?

Для інтерфейсу рахують count, а для обмежень у байтах — utf8.count.

Практика
  1. Напиши функцію, яка повертає перші n символів рядка, не падаючи, якщо рядок коротший. Підказка: prefix(_:).
  2. Порахуй для "👍🏽 ok" значення count, utf16.count, utf8.count і unicodeScalars.count. Поясни різницю.
  3. Розбери рядок "hp=100;mp=40;xp=1200" у словник [String: Int].
  4. Перевір, чи рядок — паліндром, ігноруючи регістр і пробіли.
