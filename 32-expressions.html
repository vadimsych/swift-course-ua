Довідник (за потреби) · урок 32

Довідник: вирази

Чотири види виразів у Swift — префіксні, інфіксні, первинні й постфіксні — і всі конструкції всередині них: try, await, приведення типів, if/switch-вирази, замикання, неявні члени, key paths, #selector і опціональні ланцюжки.

У книзі: expressions

Вираз обчислюється у значення, має побічні ефекти або і те, і те. Граматично вирази бувають префіксними, інфіксними (бінарними), первинними й постфіксними.

Префіксні вирази

Префіксний оператор перед виразом: -x, !flag, ~bits, а також власні префіксні оператори.

Вираз inout

&змінна — передача в inout-параметр. Дозволений лише як аргумент такого параметра (і при неявному перетворенні на вказівник, див. «Виклик функції»).

Оператор try

  • try вираз — вираз може кинути помилку, і вона поширюється далі;
  • try? вираз — результат загортається в опціонал (nil при помилці);
  • try! вираз — крах при помилці.

try стосується всього виразу праворуч від нього, тому одного try на початку вистачає навіть на кілька викликів: let price = try fetchBase() ?? fallbackPrice(). А от try посередині бінарного виразу, праворуч від оператора, поставити не можна — його переносять на початок. Виняток — присвоєння: total = try load() дозволено.

Оператор await

await вираз позначає місце, де функція може «стати на паузу». Як і try, одного await на початку виразу досить; якщо потрібні обидва — try await.

Інфіксні вирази

Бінарний оператор між двома виразами: a + b, x ?? y. Компілятор спершу читає ланцюжок операторів як плаский список, а потім групує його за пріоритетами й асоціативністю (урок 29).

Присвоєння

= замінює значення ліворуч. Якщо ліворуч кортеж, а праворуч кортеж — присвоєння поелементне:

Swift
var (hp, mana) = (100, 50)
(_, mana) = (0, 80)     // hp не змінюється

Присвоєння має тип Void і не повертає значення.

Тернарний умовний оператор

умова ? a : b — обчислює лише одну з гілок.

Оператори приведення типів

  • is — перевірка в рантаймі, повертає Bool;
  • as — приведення, відоме на етапі компіляції: вгору до суперкласу чи протоколу, до мостового типу Foundation, уточнення типу літерала;
  • as? — умовне приведення, повертає опціонал;
  • as! — примусове, крах при невдачі; x as! T поводиться як (x as? T)!.

Компілятор попередить, якщо as? гарантовано вдасться чи гарантовано провалиться. as також допомагає обрати потрібне перевантаження: log(value as Any).

Swift
let n = 7 as Double              // літерал як Double
let any: Any = "text"
let s = any as? String           // Optional("text")

Первинні вирази

Найпростіші вирази, з яких будуються решта.

Літерали

Звичайні літерали чисел, рядків, true/false, nil, а також:

Swift
let primes = [2, 3, 5, 7]                 // літерал масиву
let ages = ["Ann": 31, "Max": 28]         // літерал словника
let empty: [String: Int] = [:]

Останній елемент може мати кінцеву кому. Тип масиву чи словника виводиться з елементів; якщо типи різні, компілятор шукає спільний супертип або вимагає анотацію.

У Xcode Playgrounds є ще «playground-літерали» — #colorLiteral(...), #imageLiteral(...) — які редактор показує як кольоровий квадрат чи картинку.

#fileID, #line, #function підставляють місце в коді. Якщо зробити їх значенням параметра за замовчуванням, вони покажуть місце виклику функції — зручно для логування:

Swift
func log(_ message: String, file: String = #fileID, line: Int = #line) {
    print("[\(file):\(line)] \(message)")
}

self

self — поточний екземпляр (або тип, у статичному контексті). В ініціалізаторі value type self можна присвоїти: self = .init(...).

super

super.метод(), super.властивість, super[i], super.init(...) — звертання до реалізації суперкласу.

Умовні вирази

if і switch можуть бути виразами, якщо стоять праворуч від =, після return або як єдиний вираз у тілі функції чи замикання з результатом:

Swift
let icon = switch status {
    case .ok: "✅"
    case .warning: "⚠️"
    case .error: "⛔️"
}

Правила:

  • кожна гілка — рівно один вираз, throw або виклик функції, що не повертається;
  • if мусить мати else; усі гілки — одного типу (або вказаного анотацією);
  • умовний вираз можна використовувати як значення змінної, результат return, тіло функції чи замикання з одного виразу, операнд throw, гілку іншого умовного виразу; а от як операнд звичайного оператора (1 + if ...) — ні;
  • у result builder — лише як значення змінної чи константи;
  • не обгортай його в try — try пишуть у гілках.

Вираз-замикання

Повна форма і всі скорочення описані в уроці 7. Довідкові деталі:

  • Перед параметрами замикання може стояти список захоплення: [weak self, value]. Перелічені там значення копіюються в момент створення замикання (урок 26).
  • Атрибути типу перед списком параметрів: { @MainActor in ... }, { @Sendable (x: Int) in ... }.
  • Замикання стає async, якщо містить await, і throws, якщо містить try без обробки; якщо всі кинуті помилки одного типу, виводиться типізоване throws(E).
  • Чи є замикання escaping, визначає контекст: замикання, яке одразу викликається або передається в non-escaping параметр, вважається non-escaping.

Вираз неявного члена

.ім'я — скорочене звертання до статичного члена типу, який виводиться з контексту:

Swift
let color: UIColor = .systemOrange
view.backgroundColor = .clear
let font: Font = .system(size: 14).weight(.bold)   // ланцюжок постфіксних членів

Ланцюжок після крапки має дати значення того типу, що очікується (або сумісного з ним).

Вирази в дужках і кортежі

(вираз) — групування. (a, b) або (x: a, y: b) — кортеж. Кортеж з одного елемента — просто вираз у дужках.

Вираз-заповнювач

_ ліворуч від присвоєння явно відкидає значення:

Swift
_ = try? cache.removeAll()
let (_, second) = pair       // у зразку оголошення

Розгортання макросу

#ім'я(аргументи) — виклик freestanding-макросу (урок 19).

Key-path вирази

\Тип.властивість — посилання на властивість як значення, без звертання до неї:

Swift
struct Player { var name: String; var stats: Stats }
struct Stats { var level: Int }

let levelPath = \Player.stats.level             // WritableKeyPath<Player, Int>
var p = Player(name: "Ann", stats: Stats(level: 3))
p[keyPath: levelPath]                           // 3
p[keyPath: \.stats.level] = 4                   // WritableKeyPath, тип виводиться

let names = players.map(\.name)                 // key path як функція
let sorted = players.sorted { $0[keyPath: levelPath] > $1[keyPath: levelPath] }
  • Key path може включати сабскрипти (\[String].first, \Dictionary<String, Int>.["a"]), опціональні ланцюжки (\User.address?.city), примусове розгортання й \.self.
  • Тип залежить від можливостей: KeyPath (тільки читання), WritableKeyPath, ReferenceWritableKeyPath (для класів).
  • Key path можна передати туди, де очікується функція (Root) -> Value.
  • Аргументи сабскриптів у key path мають бути Hashable і копіюються в момент створення key path; побічні ефекти у виразі key path виконуються один раз — при створенні.
C#

Найближче — Expression<Func<T, TValue>> з LINQ, але key path у Swift — легкий типобезпечний об'єкт, а не дерево виразу. SwiftUI використовує їх скрізь: ForEach(items, id: \.id), @Environment(\.dismiss).

Вираз-селектор

#selector(метод) — ім'я методу для старих target-action API UIKit (addTarget, Timer). Метод має бути позначений @objc.

Key-path рядки

#keyPath(Тип.властивість) — рядкове ім'я властивості для Objective-C API, як KVO і NSSortDescriptor. Компілятор перевіряє, що властивість існує й доступна з Objective-C.

Постфіксні вирази

Оператор або виклик після виразу.

Виклик функції

ім'я(аргументи) з мітками; замикання наприкінці можна винести за дужки (урок 7). Тип з методом callAsFunction можна викликати як функцію.

  • &змінна для inout-параметра;
  • для параметрів-вказівників (UnsafePointer<T>) можна передати &змінна або масив — компілятор створить тимчасовий вказівник на час виклику; рядок можна передати як UnsafePointer<CChar>.

Ці вказівники дійсні лише під час виклику.

Вираз ініціалізатора

Тип.init(...) — явне посилання на ініціалізатор. Корисно, щоб передати ініціалізатор як функцію, викликати super.init або створити екземпляр динамічного типу:

Swift
let ids = ["7", "x", "42"].compactMap(Int.init)     // [7, 42]
let makeURL: (String) -> URL? = URL.init(string:)

let copy = type(of: screen).init()                   // через метатип-значення — лише з явним .init

Явне звертання до члена

вираз.член — властивість, метод або елемент кортежу (pair.0). Довгі ланцюжки можна переносити по крапці:

Swift
let result = items
    .filter { $0.isActive }
    .map(\.title)

Постфіксний self

вираз.self повертає сам вираз; Тип.self — метатип типу як значення: Int.self, [String].self.

Сабскрипт

вираз[індекс] викликає геттер або сеттер сабскрипта, зокрема з мітками й кількома аргументами.

Примусове значення

вираз! — розгортання опціоналу з крахом при nil. Через нього можна й змінювати значення: inventory["potions"]! += 1.

Опціональний ланцюжок

вираз?.член — урок 16. Усі постфіксні операції після ? в одному виразі пропускаються, якщо значення nil, а результат загортається в опціонал. Якщо ланцюжок стоїть ліворуч від присвоєння і дає nil, права частина не обчислюється.

Перевір себе

Обери відповідь — одразу побачиш, чи правильно, і пояснення.

1. Що надрукує цей код?

Swift
let flag = false
let n = 3
print(!flag, -n)

Префіксний ! інвертує false, а префіксний - змінює знак n.

2. Чому тут помилка компіляції?

Swift
func run() {
    var x = 1
    let y = &x
    print(y)
}
run()

Вираз &змінна не можна зберегти у змінну — лише передати у виклик.

3. Чому тут помилка компіляції?

Swift
struct Failure: Error {}
func fetch() throws -> Int { throw Failure() }

func run() throws {
    let total = 1 + try fetch()
    print(total)
}
try? run()

try стосується всього виразу праворуч, тому пишуть try 1 + fetch().

4. Обидві функції a() і b() — async. Скільки await потрібно у виразі let sum = await a() + b()?

Як і try, одне await на початку покриває весь вираз праворуч.

5. Що надрукує цей код?

Swift
print(2 + 3 * 4)

Ланцюжок операторів групується за пріоритетами: множення виконується раніше за додавання.

6. Що надрукує цей код?

Swift
func run() {
    var (hp, mana) = (100, 50)
    (_, mana) = (0, 80)
    print(hp, mana)
}
run()

Присвоєння кортежу поелементне, а _ пропускає перший елемент, тож hp не змінюється.

7. Що надрукує цей код?

Swift
func a() -> Int { print("a"); return 1 }
func b() -> Int { print("b"); return 2 }

let result = true ? a() : b()
print(result)

Тернарний оператор обчислює лише одну гілку, тож b() не викликається.

8. Що надрукує цей код?

Swift
let value: Any = 5
print(value is Int, value as? String ?? "none")

is повертає Bool; as? дає nil, бо значення не String, і ?? підставляє запасне значення.

9. Що станеться при запуску?

Swift
let value: Any = "7"
let number = value as! Int
print(number)

x as! T поводиться як (x as? T)! і падає, якщо приведення не вдалося.

10. Що з переліченого — первинний вираз?

Літерал — найпростіший, первинний вираз; решта — інфіксний, префіксний і постфіксний.

11. Що надрукує цей код?

Swift
func currentLine(_ line: Int = #line) -> Int { line }
print(currentLine())

#line як значення за замовчуванням підставляє рядок виклику функції, а виклик — у рядку 2.

12. Що надрукує цей код?

Swift
class A { func hi() -> String { "A" } }
class B: A {
    override func hi() -> String { super.hi() + "B" }
}
print(B().hi())

super.hi() викликає реалізацію суперкласу, до якої дописується B.

13. Чому тут помилка компіляції?

Swift
let flag = true
let total = 1 + if flag { 1 } else { 2 }
print(total)

Умовний вираз можна присвоїти, повернути чи кинути, але не підставити в 1 + ....

14. Що надрукує цей код?

Swift
func run() {
    var n = 1
    let show = { [n] in print(n) }
    n = 2
    show()
}
run()

Значення зі списку захоплення копіюється в момент створення замикання.

15. Що надрукує цей код?

Swift
enum Size {
    case small, large
    static var standard: Size { .large }
}
let size: Size = .standard
print(size)

.ім'я звертається до будь-якого статичного члена очікуваного типу, не лише до варіантів.

16. Що робить _ = compute()?

_ ліворуч від присвоєння показує, що результат свідомо не потрібен.

17. Що надрукує цей код?

Swift
struct Player { var name: String; var level: Int }
let players = [Player(name: "Ann", level: 3), Player(name: "Max", level: 5)]
print(players.map(\.name))

Key path можна передати туди, де очікується функція (Root) -> Value.

18. Що з переліченого — постфіксний вираз?

Сабскрипт стоїть після виразу, тому це постфіксний вираз.

19. Що надрукує цей код?

Swift
struct Doubler {
    func callAsFunction(_ x: Int) -> Int { x * 2 }
}
let double = Doubler()
print(double(21))

Тип з методом callAsFunction можна викликати як функцію.

20. Що надрукує цей код?

Swift
let ids = ["7", "x", "42"].compactMap(Int.init)
print(ids)

Int.init передається як функція, а compactMap відкидає nil для "x".

21. Що надрукує цей код?

Swift
func run() {
    var inventory = ["potions": 1]
    inventory["potions"]! += 1
    print(inventory["potions"]!)
}
run()

Через ! можна змінювати значення в словнику на місці.

22. Що надрукує цей код?

Swift
final class Box { var value = 0 }
func compute() -> Int { print("rhs"); return 5 }

func run() {
    let box: Box? = nil
    box?.value = compute()
    print("done")
}
run()

Якщо ланцюжок ліворуч від присвоєння дає nil, права частина не обчислюється.

Практика
  1. Відсортуй масив структур за кількома властивостями, використовуючи key paths.
  2. Напиши функцію log з #fileID і #line як значеннями за замовчуванням і переконайся, що вона виводить місце виклику, а не своє.
  3. Перетвори масив рядків у масив Int через .compactMap(Int.init) і поясни, чим це відрізняється від .map(Int.init).
  4. Напиши switch-вираз, що повертає колір для статусу підписки, і спробуй використати його як операнд +. Що скаже компілятор?
