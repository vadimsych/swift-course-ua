Вкладені типи

Як оголошувати перелічення, структури, класи й протоколи всередині інших типів, навіщо це потрібно і як до них звертатися.

У книзі: nestedtypes

Навіщо вкладати типи

Допоміжні типи, які мають сенс лише разом з іншим типом, оголошують усередині нього. Це скорочує імена й одразу показує зв'язок. Типовий приклад — опис мережевого запиту:

Swift
import Foundation

struct APIRequest {
    enum Method: String {
        case get = "GET", post = "POST", delete = "DELETE"
    }

    enum Body {
        case none
        case json([String: String])
        case form([String: String])
    }

    struct Response {
        let status: Int
        let data: Data
        var isSuccess: Bool { (200..<300).contains(status) }
    }

    var path: String
    var method: Method = .get
    var body: Body = .none
}

let request = APIRequest(path: "/purchases", method: .post,
                         body: .json(["productID": "pro_year"]))

Усередині APIRequest вкладені типи доступні за коротким ім'ям: Method, Body, Response. Memberwise-ініціалізатор теж працює з ними, а значення на кшталт .post виводяться з контексту.

Вкладати можна на будь-яку глибину, і так само в класи та enum. Є обмеження:

  • протокол можна оголосити всередині типу, але лише не generic; і навпаки, вкласти тип у протокол не можна;
  • вкладений тип не має доступу до властивостей екземпляра зовнішнього типу — це окремий тип, а не «внутрішній клас» з посиланням на зовнішній об'єкт.

Вкладений протокол зручний для делегатів:

Swift
final class Downloader {
    protocol Delegate: AnyObject {
        func downloaderDidFinish(_ d: Downloader)
    }
    weak var delegate: Delegate?
}

final class FeedController: Downloader.Delegate {
    func downloaderDidFinish(_ d: Downloader) { }
}

Звернення ззовні

Ззовні до вкладеного типу звертаються через ім'я зовнішнього:

Swift
let method = APIRequest.Method.delete
let ok = APIRequest.Response(status: 204, data: Data())

Так імена не конфліктують: APIRequest.Response і, скажімо, WebSocket.Response можуть спокійно існувати в одному модулі. Фреймворки Apple цим користуються постійно: String.Index, JSONDecoder.DateDecodingStrategy, Product.PurchaseResult, UIView.ContentMode.

C#

Це nested types, як у C#. Відмінності: у C# вкладений тип за замовчуванням private, а в Swift — той самий рівень, що й інші члени (internal), обмежений рівнем зовнішнього типу. І, як і вкладений клас у C#, вкладений тип Swift не має неявного посилання на екземпляр зовнішнього.

Перевір себе

Обери відповідь — одразу побачиш, чи правильно, і пояснення.

1. Що надрукує цей код?

Swift
struct Request {
    enum Method: String {
        case get = "GET", post = "POST"
    }
    var path: String
    var method: Method = .get
}

let a = Request(path: "/buy", method: .post)
let b = Request(path: "/list")
print(a.method.rawValue, b.method.rawValue)

Memberwise-ініціалізатор працює з вкладеним типом, а .post виводиться з контексту. Друга заявка бере значення за замовчуванням.

2. Чому тут помилка компіляції?

Swift
struct Player {
    var name = "Ann"

    struct Badge {
        func title() -> String {
            "Badge of \(name)"
        }
    }
}

Вкладений тип — окремий тип без посилання на зовнішній екземпляр.

3. Що надрукує цей код?

Swift
final class Downloader {
    protocol Delegate: AnyObject {
        func didFinish()
    }
    weak var delegate: Delegate?
    func finish() { delegate?.didFinish() }
}

final class Screen: Downloader.Delegate {
    func didFinish() { print("готово") }
}

let screen = Screen()
let downloader = Downloader()
downloader.delegate = screen
downloader.finish()

Протокол можна вкласти в не generic тип, і Screen йому відповідає як Downloader.Delegate.

4. Яке твердження неправильне?

Протокол можна оголосити лише в не generic типі.

5. Що надрукує цей код?

Swift
enum Shop {
    struct Item { let price: Int }
    enum Tier { case free, pro }
}

let item = Shop.Item(price: 5)
let tier = Shop.Tier.pro
print(item.price, tier)

Ззовні до вкладених типів звертаються через ім'я зовнішнього: Shop.Item, Shop.Tier.

6. Який рівень доступу має вкладений тип за замовчуванням?

Вкладений тип поводиться як інші члени: internal, обмежений рівнем зовнішнього типу.

Практика
  1. Зроби структуру Onboarding з вкладеним enum Step і вкладеною структурою Step.Content (заголовок, назва картинки).
  2. Створи екземпляр Onboarding.Step.Content ззовні структури.
  3. Додай у клас вкладений протокол делегата й реалізуй його в іншому класі.
  4. Спробуй оголосити протокол усередині generic-структури і прочитай повідомлення компілятора.
